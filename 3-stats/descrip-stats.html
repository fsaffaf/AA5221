Lecture 2

Descriptive Statistics

📊 Overview

There are two types of data: quantitative and qualitative. While both are important, this course focuses on quantitative data because it allows for statistical testing and hypothesis evaluation.

Quantitative = numbers for analysis | Qualitative = words for meaning

Quantitative data allows researchers to measure, calculate, and predict patterns. Qualitative data, on the other hand, provides deeper insight into experiences and perceptions.

Key idea: Statistics primarily relies on quantitative data.

📉 Descriptive vs Inferential Statistics

Statistics can be divided into two major categories, each serving a different purpose in research.

  • Descriptive statistics: Summarize and describe sample data (mean, median, mode, SD)
  • Inferential statistics: Test hypotheses and make conclusions about populations
Descriptive = describe the data | Inferential = test and generalize

Descriptive statistics also help determine whether assumptions (such as normality) are met before running inferential tests.

Key takeaway: You must understand your data before testing hypotheses.

👥 Sample vs Population

The population is the entire group of interest, while a sample is a smaller subset that researchers can realistically study.

Inferential statistics use sample data to make predictions about the population. However, these predictions are only valid if the sample accurately represents the population.

A biased sample leads to biased conclusions.

Sampling theory examines how samples are drawn and how representative they are, ensuring valid and reliable results.

Key takeaway: A good sample is essential for valid conclusions.

📌 Importance of Descriptive Statistics

Students often rush into inferential testing, but skipping descriptive statistics can lead to flawed conclusions.

  • Understand structure of data
  • Identify patterns and variability
  • Determine appropriate statistical tests
Always start with descriptives.

📊 Measures of Central Tendency

Mean

The average value. Calculated by adding all values and dividing by the total number.

Median

The midpoint of ordered data. Less affected by outliers.

Mode

The most frequently occurring value. Useful for categorical data.

Mean is sensitive to outliers; median is more robust.
Key takeaway: Different measures summarize data in different ways.

📏 Standard Deviation (SD)

Standard deviation measures how spread out data are around the mean.

  • Low SD: Data clustered near mean
  • High SD: Data widely spread
Example: (M = 10, SD = 2) → Most values fall between 8 and 12

SD provides more meaningful insight than the mean alone by describing variability in scores.

Key takeaway: SD shows how consistent or variable your data are.

📚 Levels of Measurement

Identifying the level of measurement determines which statistics, graphs, and tests are appropriate.

  • Nominal
  • Ordinal
  • Interval
  • Ratio
Categorical = Nominal + Ordinal | Continuous = Interval + Ratio

🏷️ Categorical Data

Nominal

Categories with no order (e.g., race, gender, nationality).

Ordinal

Categories with rank order but unequal spacing (e.g., Likert scales, rankings).

Key takeaway: Order may exist, but differences between levels are not equal.

📐 Continuous Data

Interval

Numerical data with no true zero (e.g., temperature in Celsius).

Ratio

Numerical data with a true zero (e.g., height, weight, distance).

Key takeaway: Ratio data allows full mathematical comparisons.

📊 Histograms vs Bar Charts

  • Histograms: Used for continuous data; bars touch; show distribution
  • Bar charts: Used for categorical data; bars separated; compare groups
Histograms check distribution, bar charts compare groups.

🔔 Normal Distribution

A normal distribution is symmetrical and bell-shaped.

  • Mean ≈ Median ≈ Mode
  • Symmetrical shape
  • Most values near center
Key idea: Many statistical tests assume normality.

📉 Skewness & Kurtosis

Skewness

  • Positive skew → tail right
  • Negative skew → tail left

Kurtosis

  • Leptokurtic → peaked
  • Mesokurtic → normal
  • Platykurtic → flat

📏 Empirical Rule

In a normal distribution:

  • 68% within ±1 SD
  • 95% within ±2 SD
  • 99.7% within ±3 SD
This rule helps estimate where most data points fall.

Even if data are not perfectly normal, this rule provides a useful approximation.

Final takeaway: SD and normality together help interpret data meaningfully.
