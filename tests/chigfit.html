RPubs

Overview

RPubs is a free publishing service that allows you to share HTML reports created from R Markdown documents online. After creating and knitting an R Markdown file into an HTML report, you can publish the report to RPubs and receive a web link that can be shared with instructors, classmates, colleagues, or other audiences.

RPubs

Think of RPubs as a simple website that hosts the HTML version of your R Markdown report. Instead of sending someone your R script, data files, graphs, and written explanations separately, RPubs allows you to share a single link displaying your completed analysis in an organized format.

Viewers do not need R, RStudio, or programming experience to view an RPubs report. Anyone with the link can open the report in a web browser and view the content included in the published document, such as written explanations, tables, graphs, and (if included) R code.

RPubs is commonly used by students, researchers, and data analysts because it provides a quick and convenient way to publish and share statistical analyses, assignments, and reports online.

How to Publish R Markdown Files to RPubs

  1. Open your R Markdown file.
  2. Click the Knit button at the top of the R Markdown document.
  3. After the HTML report appears, locate the Publish button in the Viewer pane.
  4. Select Publish to RPubs.
  5. Log in or create a free RPubs account.
  6. Enter a title and description for your report.
  7. Click Publish.
  8. Copy the generated URL and submit the link for your assignment.
Important: Always click Knit before publishing. RPubs publishes the HTML file generated by R Markdown, not the .Rmd file itself.

How to Update an RPubs Report

  1. Open your R Markdown file and make your edits.
  2. Click Knit to generate an updated HTML report.
  3. Click Publish.
  4. Select Yes when asked whether you want to update the existing document.
Updating the existing RPubs document allows you to keep the same web link while replacing the old report with your revised version.

How to Save an RPubs HTML File to Microsoft OneDrive

In some assignments you may want to save a copy of your published RPubs report inside Microsoft OneDrive for backup or record-keeping purposes.

  1. Open your RPubs report in a web browser.
  2. Press Ctrl + S (Windows) or Command + S (Mac).
  3. Select a location on your computer.
  4. Choose Webpage, HTML Only if available.
  5. Save the file.
Depending on your browser, the exact save options may vary slightly. The goal is to save a copy of the HTML webpage generated by RPubs.

Key Takeaway

RPubs allows you to transform an R Markdown report into a shareable website. Anyone with the link can view your completed analysis, tables, figures, and written explanations without needing R or RStudio.

In this course, RPubs will be used to publish and share completed R Markdown assignments. By combining R Markdown and RPubs, you can create professional, reproducible reports that are easy to distribute and review.
