Part 7: Conduct a Chi-Square Goodness-of-Fit Test

Step 1: Create Expected Proportions

expected <- c(#, #, #)

Replace the placeholders with the expected proportions from the assignment scenario.

Expected proportions must add up to 1.00 (100%).

Example

expected <- c(.40, .20, .40)

Step 2: Conduct the Test

chi_result <- chisq.test(
  x = observed,
  p = expected
)

chi_result

Example Output

Chi-squared test for given probabilities

data: observed
X-squared = 12.64
df = 2
p-value = 0.009

Part 8: Determine Statistical Significance

Compare the p-value to .05.

P-Value Decision
p < .05 Statistically Significant
p > .05 Not Statistically Significant

Part 9: Calculate Cohen's W

w <- sqrt(as.numeric(chi_result$statistic) /
          sum(observed))

w

Interpretation Guidelines

Cohen's W Interpretation
< 0.10 Negligible Difference
0.10 - 0.29 Small Difference
0.30 - 0.49 Moderate Difference
0.50+ Large Difference
