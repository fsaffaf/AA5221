Lecture 6.1: Independent T-Test & Mann-Whitney U Test

Independent Samples & Normality
Overview

An Independent T-Test allows you to determine if there is a difference between the scores of two different groups (known as a between-subjects design).

If the score data for both groups is normally distributed, you use an Independent T-Test.

If the score data for one or both groups is abnormally distributed, you switch to a Mann-Whitney U test.

Today's Decision:

The normality checks in this lesson will help you determine which statistical test to use.

Normal data → Independent T-Test
Abnormal data → Mann-Whitney U Test

Component Structure Example
Research Question Is there a mean difference between two independent groups? Is there a difference in exam scores between online students and in-person students?
Null Hypothesis There is NO difference between the two group means. There is NO difference in exam scores between online and in-person students.
Alternative Hypothesis There IS a difference between the two group means. There IS a difference in exam scores between online and in-person students.

Step 8: Interpret the Boxplots

Directions

  • In RScript, report if each boxplot was normal or not normal.
  • This method for checking outliers is simplified for class.
Question 1: Were there any dots outside the boxplot?
  • If no dots, data is normal. Stop. Do not answer more.
  • If dots, continue.
Question 2: Are dots past whiskers?

Whiskers are the lines extending from the boxplot.

  • If dots are not past whiskers, data is normal. Stop.
  • If dots are past whiskers, continue.
Question 3: Are dots VERY far away from whiskers?
  • If not very far, data is normal. Stop.
  • If VERY far, continue.
Question 4: Are outliers balanced or unbalanced?

Balanced outliers occur when there are generally equal numbers on each side and the outliers are a similar distance from the boxplot. These outliers generally “cancel out,” and the data stays generally balanced.

  • If balanced, normal.
  • If primarily on one side and not equally balanced, NOT normal.

Directions

Step 14a
Report the Independent T-Test

Directions

  • After analyses, report findings in a few clear sentences in RScript.
  • Copy the template and replace the highlighted portions with your output results.
  • This is a standardized method. DO NOT be creative.

P-Value Reporting

  • p < .001 → report p < .001
  • .001 < p < .05 → report the exact p-value to three numbers after the decimal (example: p = .003)
  • p > .05 → report p > .05
  • All other values: report two places after the decimal. Example: .1252 becomes .13.

Definitions

  • M = mean
  • SD = standard deviation
  • df = degrees of freedom
  • t = t-test value
  • p = p-value

Degrees of freedom represent the total sample size minus the number of groups. For an Independent T-Test, there are always two groups. For example, if n = 100, then 100 − 2 = 98 degrees of freedom. This helps readers understand the sample size and how the p-value was calculated.

Effect Size

Only report effect size when the test is statistically significant (p < .05).

Correlation is special because the effect size is automatically provided. The r-value is the effect size.

  • ± 0.00 to 0.19 = no difference between groups
  • ± 0.20 to 0.49 = small difference
  • ± 0.50 to 0.79 = medium difference
  • ± 0.80 to 1.29 = large difference
  • ± 1.30 and higher = very large difference

Report Template

#An Independent T-Test was conducted to determine if there was a difference in OutcomeVariable between Group1 and Group2.
#Group 1 scores (M = xx.xx, SD = xx.xx) were [significantly / not significantly] different from Group2 scores (M = xx.xx, SD = xx.xx), t(df#) = x.xx, p = .xxx.
#The effect size was [small / medium / large / very large], Cohen's d = .xxx.

Example

#An Independent T-Test was conducted to determine if there was a difference in Exam Scores between Females and Males.
#Female scores (M = 83.00, SD = 7.50) were significantly different from Male scores (M = 76.70, SD = 6.00), t(98) = 2.01, p = .002.
#The effect size was medium, Cohen's d = .65.
