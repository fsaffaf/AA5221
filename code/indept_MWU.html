Independent T-Test & Mann-Whitney U Test

Steps to Conduct an Independent t-test (or Mann-Whitney U) in RStudio

Overview of the Test

An Independent T-Test allows you to determine if there is a difference between the scores of two different groups (known as a between-subjects design).

If the score data for both groups is normally distributed, you use an Independent T-Test.

If the score data for one or both groups is abnormally distributed, you switch to a Mann-Whitney U test.

Today's Decision:

The normality checks in this lesson will help you determine which statistical test to use.

Normal data → Independent T-Test
Abnormal data → Mann-Whitney U Test

Research Question General Question Example
Research Question Is there a mean difference between two independent groups? Is there a difference in exam scores between online students and in-person students?
Null Hypothesis There is NO difference between the two group means. There is NO difference in exam scores between online and in-person students.
Alternative Hypothesis There IS a difference between the two group means. There IS a difference in exam scores between online and in-person students.

Interpret the Boxplots

In your R Script, report if each boxplot was normal or not normal.

Important: This method for checking outliers is simplified for this class.

Question 1: Were there any dots outside the boxplot?

  • If there are no dots, the data is normal. Stop. Do not answer more questions.
  • If there are dots, continue to Question 2.

Question 2: Are the dots past the whiskers?

Whiskers are the lines extending from the boxplot.

  • If the dots are not past the whiskers, the data is normal. Stop.
  • If the dots are past the whiskers, continue to Question 3.

Question 3: Are the dots VERY far away from the whiskers?

  • If the dots are not very far away, the data is normal. Stop.
  • If the dots are VERY far away, continue to Question 4.

Question 4: Are the outliers balanced or unbalanced?

Balanced: Generally equal numbers of outliers on each side and similar distance from the boxplot. These generally "cancel out," so the data stays generally balanced.

  • If the outliers are balanced, the data is normal.
  • If the outliers are primarily on one side and are not equally balanced, the data is NOT normal.

Independent T-Test

Use this path when your data are normally distributed.

Step 8a
Conduct the Independent T-Test

Conduct an Independent T-Test to determine whether there is a difference between groups.

  • For simplicity, assume equal variances and use var.equal = TRUE.
  • In advanced analyses, Levene's Test is often used to assess equality of variances.

Code Template

t.test(OutcomeVariable ~ GroupVariable, data = DatasetName, var.equal = TRUE)

Example

t.test(ExamScores ~ Gender, data = DatasetZ, var.equal = TRUE)

Output:

Two Sample t-test

data: score by gender

t = 2.01, df = 98, p-value = 0.002

mean in group Female = 83.0
mean in group Male = 76.7
Step 9a
Calculate Cohen's d

Only calculate Cohen's d if the Independent T-Test is significant (p < .05).

Code Template

cohens_d_result <- cohens_d(OutcomeVariable ~ GroupVariable,
                             data = DatasetName,
                             pooled_sd = TRUE)
print(cohens_d_result)

Example

cohens_d_result <- cohens_d(ExamScores ~ Gender,
                             data = DatasetZ,
                             pooled_sd = TRUE)
print(cohens_d_result)

Output: 0.65

Step 10a
Report the Independent T-Test

After the analyses, report your findings in a few clear sentences in your R Script.

Copy the template and replace the highlighted portions with your output results.

Standardized Method: DO NOT be creative. Use the provided reporting format.

P-Value Reporting

  • p < .001 → report p < .001
  • .001 < p < .05 → report the exact p-value to three decimals (example: p = .003)
  • p > .05 → report p > .05
  • All other values → report two decimal places (example: .1252 → .13)

Definitions

  • M = mean
  • SD = standard deviation
  • df = degrees of freedom
  • t = t-test value
  • p = p-value

Degrees of Freedom: Total sample size minus the number of groups. For two groups, if n = 100, then df = 98.

Effect Size:

Only report the effect size when the test is significant (p < .05).

Correlation is special because the effect size is automatically provided. The r-value is the effect size.

Effect Size Interpretation
±0.00–0.19 No difference between groups
±0.20–0.49 Small difference
±0.50–0.79 Medium difference
±0.80–1.29 Large difference
±1.30+ Very large difference

#The effect size was [small / medium / large / very large], Cohen's d = .xxx.
