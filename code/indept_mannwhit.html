Lecture 6.1: Independent T-Test & Mann-Whitney U Test

Overview

An Independent T-Test allows you to determine if there is a difference between the scores of two different groups. This is known as a between-subjects design.

If the score data for both groups is normally distributed, you use an Independent T-Test.

If the score data for one or both groups is abnormally distributed, you switch to a Mann-Whitney U test.

Component Structure Example
Research Question Is there a mean difference between two independent groups? Is there a difference in exam scores between online students and in-person students?
Null Hypothesis There is NO difference between the two group means. There is NO difference in exam scores between online and in-person students.
Alternative Hypothesis There IS a difference between the two group means. There IS a difference in exam scores between online and in-person students.

Step 8: Interpret the Boxplots

Directions

In your RScript, report if each boxplot was normal or not normal.

Important: This method for checking for outliers is simplified for our class.

Question 1

Were there any dots outside of the boxplot?

If there are no dots, the data is normal. Stop here. Do not answer any more boxplot questions.

If there are dots, continue to Question 2.

Question 2

Are the dots past the whiskers of the boxplot? The whiskers are the lines on the boxplot.

If the dots are not past the whiskers, the data is normal. Stop here. Do not answer any more boxplot questions.

If the dots are past the whiskers, continue to Question 3.

Question 3

Are the dots VERY far away from the whiskers?

If the dots are not very far away, the data is normal. Stop here. Do not answer any more boxplot questions.

If the dots are VERY far away, continue to Question 4.

Question 4

Are the outliers balanced or unbalanced?

Balanced outliers occur when there are generally an equal number of outliers on each side of the boxplot and they are a similar distance from the boxplot. These outliers "cancel out" each other and keep the data generally balanced.

If the dots are balanced, the data is normal.

If the dots are primarily on one side of the boxplot and do not have an equal balance on the other side, the data is NOT normal.

Step 10: Interpret the Shapiro-Wilk Test

Directions

In your RScript, report if the data is normal or abnormal according to the Shapiro-Wilk tests.

The Shapiro-Wilk test is testing:

"Is there a significant difference between my data's distribution and a theoretically perfect normal distribution?"

Shapiro-Wilk P-Value Meaning Result
p > .05 There is NO significant difference between our data's distribution and a normal distribution. Data is normal
p < .05 There is a significant difference between our data's distribution and a normal distribution. Data is abnormal

Step 12a: Conduct the Independent T-Test

Directions

Conduct the Independent T-Test to determine whether there is a difference between the two groups.

Course Assumption: For simplicity in this course, we assume equal variances between groups and use var.equal = TRUE.

In more advanced analyses, Levene's Test is often used to assess equality of variances.

Code Template

t.test(
    OutcomeVariable ~ GroupVariable,
    data = DatasetName,
    var.equal = TRUE
)

Example Code

t.test(
    ExamScores ~ Gender,
    data = DatasetZ,
    var.equal = TRUE
)

Step 14a: Report the Independent T-Test

General Reporting Directions

After conducting your analyses, report what you found in a few clear sentences in your RScript.

Copy the template below and replace the highlighted portions with your output results.

Important: This is the standardized method for reporting results. Do NOT be creative.

P-Value Reporting Directions

  • p < .001 = report p < .001
  • .001 < p < .05 = report the exact p-value to three decimal places, such as p = .003
  • p > .05 = report p > .05

Reporting Directions for All Other Values

Report numbers to two places after the decimal. Remember to round.

Example: .1252 becomes .13

Definitions

Symbol Definition
M Mean
SD Standard deviation
df Degrees of freedom. For an independent t-test, degrees of freedom are the total sample size minus the number of groups being compared.
t T-test value
p P-value

For an independent t-test, the number of groups is always two. For example, if the sample size is 100, then: 

100 - 2 = 98

Degrees of freedom help the computer calculate the p-value and provide the reader with information about the sample size and how the p-value was calculated.

Effect Size Directions

What is an effect size?

Only report the effect size when your results are statistically significant (p < .05).

Correlation is special because the effect size is automatically provided. The r-value (correlation value) is the effect size.

Effect Size Interpretation
± 0.00 to 0.19 No difference between groups
± 0.20 to 0.49 Small difference between groups
± 0.50 to 0.79 Medium difference between groups
± 0.80 to 1.29 Large difference between groups
± 1.30 and higher Very large difference between groups

# The effect size was [small / medium / large / very large], Cohen's d = .xxx.
