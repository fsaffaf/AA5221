Chi-Square Goodness-of-Fit Test

Overview

The Chi-Square Goodness-of-Fit test is used for categorical data only.

It allows you to determine whether the distribution of one categorical variable matches an expected distribution.

In this context, distribution refers to how participants are distributed across the categories of a variable. Normality does not apply because categorical data cannot be represented on a histogram.

The research design is observational. Therefore, there is no independent variable (IV) and no dependent variable (DV).

Component General Structure Example
Research Question Is the current frequency distribution of the variable the same as the expected frequency distribution? Is the current frequency distribution of political parties among SLU students (2026) the same as the previous year (2025)?
Null Hypothesis There is no difference between the observed and expected frequencies. There is no difference between the observed political party frequencies and the expected frequencies.
Alternative Hypothesis There is a difference between the observed and expected frequencies. There is a difference between the observed political party frequencies and the expected frequencies.

The Chi-Square Goodness-of-Fit test compares the frequencies observed in a dataset to frequencies that are expected based on historical data, previous research, or a theoretical expectation.

Example Expected Distribution

  • 40% Democrat
  • 20% Independent
  • 40% Republican

These percentages become the expected proportions used in the analysis.

Important: Expected proportions must always add up to 100% (1.00).

Understanding Observed Frequencies

The values in the frequency table are called observed frequencies. These are the actual category counts found in your dataset.

The Chi-Square Goodness-of-Fit test compares:

  • Observed Frequencies → What you found in your dataset.
  • Expected Frequencies → What you expected to find based on previous research, theory, or historical data.

Part 7: Conduct a Chi-Square Goodness-of-Fit Test

The Chi-Square Goodness-of-Fit test compares the frequencies observed in your dataset to frequencies that were expected based on prior research, historical data, or a theoretical expectation.

Before conducting the test, you must create a vector containing the expected proportions.

Step 1: Create the Expected Proportions

  1. Return to the research scenario provided with your assignment.
  2. Locate the expected percentages for each category.
  3. Convert each percentage to a decimal.
  4. Enter the decimals into a vector named expected.
  5. Ensure the order of the expected proportions matches the order of the categories shown in your frequency table.

Code Template

expected <- c(#, #, #)

Replace the hashtags with the expected proportions from your research scenario.

Order Matters

The expected proportions must appear in the same order as the categories displayed in your frequency table.

Suppose your frequency table displays: 

Democrat
Independent
Republican

Then your expected proportions must follow the same order. 

expected <- c(.40, .20, .40)

  • 20% Independent → 0.20
  • 40% Republican → 0.40

Important: Expected proportions must add up to 1.00 (100%).

Running this line of code will not produce any output. That is normal.

Step 2: Conduct the Chi-Square Goodness-of-Fit Test

Once the observed frequencies and expected proportions have been created, use the chisq.test() function to perform the analysis. 

chi_result <- chisq.test(
x = observed,
p = expected
)

chi_result

The first line performs the Chi-Square Goodness-of-Fit test. The second line displays the results.

Example Output

Chi-squared test for given probabilities

data: observed

X-squared = 12.64

df = 2

p-value = 0.009
Understanding the Output

The Chi-Square output contains three values that are used when reporting results.

Statistic Meaning
X-squared (χ²) The Chi-Square test statistic. Larger values indicate greater differences between the observed and expected frequencies.
Degrees of Freedom (df) Used to determine the sampling distribution for the test. For a Goodness-of-Fit test:

df = Number of Categories − 1
P-Value Used to determine whether the result is statistically significant.
Example Interpretation

Suppose the output produced the following values: 

X-squared = 12.64

df = 2

p-value = .009

This indicates that the observed frequencies differed from the expected frequencies by an amount represented by χ² = 12.64.

The p-value will be used in the next section to determine whether this difference is statistically significant.

Important: Do not make a conclusion yet. First determine whether the p-value is statistically significant. This will be completed in Part 8.

Part 8: Determine Statistical Significance

After running the Chi-Square Goodness-of-Fit test, the next step is to determine whether the observed distribution differs significantly from the expected distribution.

To make this decision, compare the p-value from your output to the significance level of .05.

Decision Rule

P-Value Decision Conclusion
p < .05 Statistically Significant The observed frequencies differ from the expected frequencies.
p > .05 Not Statistically Significant The observed frequencies do not differ enough from the expected frequencies to conclude that a real difference exists.
What Does Statistical Significance Mean?

A statistically significant result suggests that the differences between the observed and expected frequencies are unlikely to be explained by random variation alone.

Statistically Significant: The observed distribution differs from the expected distribution.

A non-significant result suggests that any differences between the observed and expected frequencies are small enough that they could reasonably be due to chance.

Not Statistically Significant: The observed distribution is similar to the expected distribution.

Example 1: Statistically Significant Result

Suppose your Chi-Square output is: 

X-squared = 12.64

df = 2

p-value = .009

Since:

.009 < .05

The result is statistically significant.

This means the observed frequencies differ from the expected frequencies.

Example 2: Not Statistically Significant

Suppose your Chi-Square output is: 

X-squared = 1.82

df = 2

p-value = .403

Since:

.403 > .05

The result is not statistically significant.

This means the observed frequencies do not differ enough from the expected frequencies to conclude that a meaningful difference exists.

Decision-Making Workflow
  1. Locate the p-value in the Chi-Square output.
  2. Compare the p-value to .05.
  3. If the p-value is less than .05, conclude that the result is statistically significant.
  4. If the p-value is greater than .05, conclude that the result is not statistically significant.
  5. Only calculate Cohen's W if the result is statistically significant.

Important: If your result is not statistically significant (p > .05), you should not calculate or interpret Cohen's W for this assignment. Proceed directly to writing your results summary.

Part 9: Calculate Cohen's W

If your Chi-Square Goodness-of-Fit test is statistically significant (p < .05), the next step is to calculate an effect size.

For Chi-Square Goodness-of-Fit tests, the effect size is Cohen's W.

Cohen's W describes the magnitude of the difference between the observed and expected distributions.

Remember: Only calculate and interpret Cohen's W if your Chi-Square test was statistically significant.

Step 1: Calculate Cohen's W

Copy and paste the following code into your R Script. 

w <- sqrt(
as.numeric(chi_result$statistic) /
sum(observed)
)

w

The first line calculates Cohen's W. The second line displays the result.

Example Output

0.40

This value represents the magnitude of the discrepancy between the observed and expected frequencies.

Interpreting Cohen's W

Use the table below to classify the size of the effect.

Cohen's W Interpretation
Less than 0.10 Negligible Difference
0.10 - 0.29 Small Difference
0.30 - 0.49 Moderate Difference
0.50 or Higher Large Difference
Example Interpretation

Suppose your output produced: 

w = 0.40

Since 0.40 falls between 0.30 and 0.49, the effect size would be interpreted as a moderate difference.

This indicates that the observed frequencies differ from the expected frequencies by a moderate amount.

Reporting Cohen's W

When reporting results, include a verbal interpretation of Cohen's W.

Cohen's W Example Sentence
0.08 The difference was negligible (Cohen's W = .08).
0.20 The difference was small (Cohen's W = .20).
0.40 The difference was moderate (Cohen's W = .40).
0.62 The difference was large (Cohen's W = .62).
