R Script Code Template

Below is an example of what your code will look like. Your code will be different because the dataset name, variable names, results, and interpretations will depend on your assigned dataset.

library(rcompanion)
library(ggplot2)

data2026 <- read_excel("C:/Users/John/OneDrive/Documents/AA5221/Datasets/political_data.xlsx")

polit_table

    polit_table,
    beside = TRUE,
    col = rainbow(nrow(polit_table)),

cramer_v <- rcompanion::cramerV(polit_table)

Part 8
Determine Statistical Significance

After running the Chi-Square test, compare the p-value to .05.

P-Value Decision
p < .05 Statistically Significant
p > .05 Not Statistically Significant

What this means:

A statistically significant result suggests that there is an association between the two categorical variables.

A non-significant result suggests that there is not enough evidence to conclude that the two variables are associated.

Part 9
Calculate the Effect Size

Only calculate Cramér's V if your Chi-Square Test is statistically significant (p < .05).

Step 1
Calculate Cramér's V

Cramér's V describes the strength of the association between the two categorical variables.

Example code: 

cramer_v <- rcompanion::cramerV(polit_table)

cramer_v

Example output: 

0.32

Interpreting Cramér's V

Cramér's V Interpretation
0.10 or less Negligible association
0.10–0.29 Small association
0.30–0.49 Moderate association
0.50 or higher Large association
Part 10
Report the Results
Step 1
Report P-Values

After completing the analysis, summarize the results as comments at the end of your R Script. Begin each sentence with a hashtag (#).

  • If your p-value is less than .001, report p < .001.
  • If your p-value is greater than .001 but less than .05, report the exact p-value to three decimal places (e.g., p = .003).
  • If your p-value is greater than .05, report p > .05.
Step 2
Report Other Numerical Values

Report other numerical values to two decimal places. Remember to round.

For example: .1252 → .13

Step 3
Use the Reporting Template 
# A Chi-Square Test of Independence was conducted to determine if there was an association between Variable 1 and Variable 2.

# The results showed that there [was / was not] an association between the two variables, χ²(df) = xx.xx, p = .xxx.

# The association was [negligible / small / moderate / large] (Cramer's V = .xx).
