Step 7
Check Normality Visually: Histograms

Checking normality is extremely important when determining whether a Pearson or Spearman Correlation should be used.

Therefore, we check normality in multiple ways. The first method is a visual inspection using histograms.

A histogram displays the distribution of a variable and allows you to look for skewness, symmetry, and the presence of a bell curve.

Create Histograms

Create a histogram for each variable.

Code Template

hist(DatasetName$IndependentVariable,
     main = "Independent Variable",
     breaks = 20,
     col = "lightblue",
     border = "white",
     cex.main = 1,
     cex.axis = 1,
     cex.lab = 1)

hist(DatasetName$DependentVariable,
     main = "Dependent Variable",
     breaks = 20,
     col = "lightcoral",
     border = "white",
     cex.main = 1,
     cex.axis = 1,
     cex.lab = 1)

Example with Pretend Data

hist(DatasetZ$Age,
     main = "Age",
     breaks = 20,
     col = "lightblue",
     border = "white")

hist(DatasetZ$USD,
     main = "USD",
     breaks = 20,
     col = "lightcoral",
     border = "white")

What will you see?
Two histograms showing the distribution of each variable.

Write your comments directly below the histogram code in your R Script.

For each variable, determine:

  • Whether the variable appears normally or abnormally distributed.
  • Whether the variable is symmetrical, positively skewed, or negatively skewed.
  • Whether the histogram displays a proper bell curve.

Normality Guidelines

  • Normally distributed data are generally symmetrical and have a bell-shaped curve.
  • Positively skewed data have a longer tail on the right side.
  • Negatively skewed data have a longer tail on the left side.
  • Abnormal skewness or abnormal kurtosis indicates non-normal data.

Step 9
Check Normality Statistically: Shapiro-Wilk Test

The Shapiro-Wilk test provides a statistical method for checking normality. Unlike visual inspection, the Shapiro-Wilk test evaluates whether the observed distribution differs significantly from a theoretically normal distribution.

Run the Shapiro-Wilk Tests

Copy and paste the following code into your R Script: 

shapiro.test(DatasetName$IndependentVariable)

shapiro.test(DatasetName$DependentVariable)

Example with Pretend Data

shapiro.test(DatasetZ$Age)

shapiro.test(DatasetZ$USD)

Example Output

Shapiro-Wilk normality test

data: DatasetZ$Age
W = 0.959
p-value = 0.754

Shapiro-Wilk normality test

data: DatasetZ$USD
W = 0.970
p-value = 0.865

The Shapiro-Wilk test evaluates the following question:

"Is there a statistically significant difference between my data's distribution and a perfectly normal distribution?"
P-Value Meaning Conclusion
p > .05 No significant difference from a normal distribution Normal
p < .05 Significant difference from a normal distribution Abnormal

Reporting Template

# Variable 1: Name of Variable
# The variable is [normally / abnormally] distributed (p = .xx).

# Variable 2: Name of Variable
# The variable is [normally / abnormally] distributed (p = .xx).

Example Report

# Variable 1: Age
# The variable is normally distributed (p = .75).

# Variable 2: USD
# The variable is normally distributed (p = .87).
Step 11
Determine Which Correlation to Use

Use the information from your histograms and Shapiro-Wilk tests to determine whether you should conduct a Pearson Correlation or a Spearman Correlation.

Scenario Decision
Both histograms appear normal and both Shapiro-Wilk tests indicate normality. Use Pearson Correlation.
One or both histograms appear abnormal, but both Shapiro-Wilk tests indicate normality. You most likely have misinterpreted the histograms. Check your Shapiro-Wilk tests for the answer on whether the data are normal or not. The datasets for this assignment are designed so that the histograms and Shapiro-Wilk tests match. In real-world data, the two methods can sometimes disagree. When they disagree, this may indicate that the data need additional investigation, such as checking for data-entry errors or methodological problems.
One or both Shapiro-Wilk tests indicate abnormality. Use Spearman Correlation.
Important:

For this assignment, follow the decision rule above. If one or both Shapiro-Wilk tests indicate abnormality, conduct a Spearman Correlation.

Once you determine which correlation is appropriate, continue to either the Pearson Correlation section or the Spearman Correlation section.

Option A: Pearson Correlation

Step 12a
Conduct the Pearson Correlation

If both variables are normally distributed, conduct a Pearson Correlation.

The Pearson Correlation measures the strength and direction of a linear relationship between two variables.

Replace the dataset and variable names with the names used in your dataset.

How to Report P-Values

  • If p < .001, report p < .001.
  • If .001 < p < .05, report the exact p-value to three decimal places.
  • If p > .05, report p > .05.

Reporting Other Numerical Values

Report all other numerical values to two decimal places. Remember to round.

Example: .1252 → .13

Interpreting Effect Size

For correlations, the effect size is the correlation coefficient itself (r). Unlike tests such as chi-square tests where a separate effect size may be calculated, correlation analysis directly produces a measure of effect size.

The value of r tells us both the direction and strength of the relationship between two variables, so no additional effect size calculation is needed.

Only interpret the effect size if your results are statistically significant (p < .05).

Correlation Value Interpretation
± 0.00 to 0.09 No Relationship
± 0.10 to 0.29 Weak Relationship
± 0.30 to 0.49 Moderate Relationship
± 0.50 to 1.00 Strong Relationship
