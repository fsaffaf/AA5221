Overview

Correlation allows you to determine the relationship between two continuous variables.

If both variables are normally distributed, use a Pearson correlation. If one or both are not normally distributed, use a Spearman correlation.

Component Structure Example
Research Question Is there a relationship between Variable A and Variable B? Is there a relationship between Age and Income (USD)?
Null Hypothesis There is no relationship between Variable A and Variable B. There is no relationship between Age and Income.
Alternate Hypothesis There is a relationship between Variable A and Variable B. There is a relationship between Age and Income.
Step 1: Install Required Packages 
install.packages("readxl")
install.packages("ggpubr")
Step 2: Load Packages 
library(readxl)
library(ggpubr)
Step 3: Import Dataset 
DatasetZ <- read_excel("C:/Users/Username/Desktop/dataset.xlsx")
Step 4: Create Scatterplot 
ggscatter(
  DatasetZ,
  x = "Age",
  y = "USD",
  add = "reg.line",
  xlab = "Age",
  ylab = "Income (USD)"
)
Step 10: Pearson Correlation 
cor.test(DatasetZ$Age, DatasetZ$USD, method = "pearson")
Step 10 (Backup): Spearman Correlation 
cor.test(DatasetZ$Age, DatasetZ$USD, method = "spearman")
