Overview

This page provides directions on how to convert your R Script file (code file) into an R Markdown file (presentation file), and then into an RPubs URL (a shareable HTML file).

Why convert R Script to R Markdown?
R Scripts save only code. R Markdown combines code, explanations, and results into a single well‑formatted document.

Why publish on RPubs?
RPubs allows anyone to view your results via a URL without needing RStudio.
