Statistics & Hypothesis Testing

OVERVIEW

There are two types of statistics: Descriptive Statistics and Inferential Statistics. Each plays a critical role in analyzing and interpreting data.

Descriptive Statistics: Summarize and organize a dataset using measures such as means, standard deviations, frequencies, and percentages. They also help determine whether data are normally distributed using tools like histograms, skewness, and kurtosis.
Inferential Statistics: Used to test hypotheses and determine whether results support the null or alternate hypothesis. The test you choose depends on research design, variables, and data distribution.

SCIENTIFIC HYPOTHESES

Researchers test two competing hypotheses. The structure depends on the research design being used.

Null Hypothesis: Nothing happens → No relationship OR no group difference.
Alternate Hypothesis: Something happens → A relationship OR a group difference exists.

Examples by Research Design

Design Null Alternate
Correlational No relationship between variables There IS a relationship
Experiment / Quasi No difference between groups There IS a difference

HOW HYPOTHESIS TESTING WORKS

You must understand the following concepts:

  • p-value
  • alpha (α)
  • statistical significance
  • effect size
P-Value: Represents probability (0 to 1). Smaller p-values support the alternate hypothesis, larger values support the null.
Alpha Level (α): Benchmark for comparison. Common values: 0.05, 0.01, 0.001. In this course, we use α = 0.05.
Statistical Significance: If p < 0.05 → results are significant → alternate hypothesis supported.

INTERPRETING RESULTS

Result Hypothesis Conclusion
p ≥ .05 Null supported NOT statistically significant
p < .05 Alternate supported Statistically significant

EFFECT SIZE

Effect size tells us how strong a relationship is or how large a group difference is.

Key Rule: Only calculate and report effect size when results are statistically significant.
  • Correlational: strength of relationship
  • Experimental: size of group difference

Statistical significance tells us if something happened, effect size tells us how important it is.

PUTTING IT ALL TOGETHER

p-value Hypothesis Report Effect Size?
p ≥ .05 Null Not significant No
p < .05 Alternate Significant Yes (small/medium/large)
