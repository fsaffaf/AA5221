Statistics & Hypothesis Testing

OVERVIEW

There are two types of statistics: Descriptive Statistics and Inferential Statistics. Each plays a critical role in analyzing and interpreting data.

Descriptive Statistics: These statistics describe and summarize your dataset. This includes commonly known statistics like simple averages, frequencies, and percentages. This also includes less commonly known statistics like standard deviations and normality tests. Descriptive statistics can be displayed numerically (as plain numbers) and visually (as histograms, bar graphs, etc).
Inferential Statistics: These statistics are used to test your hypothesis. Specifically, they are used to determine if the null or alternate was supported by the data. They are called inferential statiatics because you draw "inferences" (interpret the results) from your data. There are many different inferential tests. The test you choose depends on research design, variable type, and data distribution (determined by your descriptive statistics).

SCIENTIFIC HYPOTHESES

Researchers test two competing hypotheses. The structure depends on the research design being used.

Null Hypothesis: This hypothesis claims nothing has happened. For a correlational study, we write this as "There is NO relationship between the variables." For a quasi-experiment or true experiment, we write this as "There is NO difference between the groups."
Alternate Hypothesis: This hypothesis claims something HAS happened. For a correlational study, we write this as "There IS relationship between the variables." For a quasi-experiment or true experiment, we write this as "There IS a difference between the groups."

HOW HYPOTHESIS TESTING WORKS

You must understand the following concepts:

  • p-value
  • alpha (α)
  • statistical significance
  • effect size

P-Value

P-Value: The p-value (or probability value) is the likelihood that your null versus hypothesis is true.
The p-value ranges from 0 to 1, which represents a likelihood from 0 to 100%. The closer the value is to 0, the more support there is for the alternate hypothesis. The closer the value is to 1, the more support there is for the null hypothesis.

Alpha Value

Alpha Level (α): Benchmark for interpreting the p-value. The most common alpha value is .05 (or 5%).
P-values are interpreted by comparing them to benchmarks called alpha levels (α). In scientific research, there are three standard alpha levels: 0.05, 0.01, and 0.001. The most common alpha level (and the one we will use in our class) is 0.05.

Statistical Significance

Statistical Significance: Statistical significance occurs when your obtained p-value is less than your set alpha value. Achieving statistical significance means that your alternate hypothesis is supported.

If p ≥ .05 (if the obtained p-value is greater than or equal to our set alpha value of .05), then this means there is a 5% (or greater) chance your null hypothesis is true. This is too high according to scientific standards. Therefore, your results are NOT statistically significant. The null hypothesis is supported.

If p < .05 (if the obtained p-value is less than our set alpha value of .05), then this means there isless than a 5% chance your null hypothesis is true. This is low enough according to scientific standards. Therefore, your results ARE statistically significant. The alternate hypothesis is supported.

EFFECT SIZE

Effect Size: A statistical test calculated after the alternate hypothesis is suppoeted. The effect size tells us how strong a relationship is or how large a group difference is. You should only calculate and report effect size when results are statistically significant. If the results are not statistically significant, this automatically means the effect size is extremely weak/ non-existant.

If the results are statistically significant, the next step is to determine the size of the effect. Statistical significance tells us if something happened, effect size tells us how important it is.

For correlational research, the effect size tells us how strong the relationship was between the independent and dependent variable.

For quasi-experiments and true experiments, the effect size tells us how big the difference was between Group A and Group B.

Each inferential test requires its own specific effect size test.
