Purpose

Understand the full lifecycle of data analytics.

This overview shows how all steps connect into one process.

1. Define Problem

Set research questions and goals.

Example: What factors influence student performance?

2. Planning

Define scope and requirements.

Identify stakeholders, constraints, and needed data.

3. Data Collection

Gather relevant data sources.

Sources include surveys, APIs, databases, or experiments.

4. Data Cleaning

Prepare and clean the dataset.

Remove missing data, fix errors, standardize formats.

5. Exploratory Analysis

Identify patterns and trends.

Use charts, distributions, and summary statistics.
