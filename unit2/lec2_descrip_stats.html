Descriptive Statistic Definition Data Type

There are two types of statistics: Descriptive Statistics and Inferential Statistics. Each plays a critical role in analyzing and interpreting data.

Descriptive Statistics: These statistics describe and summarize your dataset. This includes commonly known statistics like simple averages, frequencies, and percentages. This also includes less commonly known statistics like standard deviations and normality tests. Descriptive statistics can be displayed numerically (as plain numbers) and visually (as histograms, bar graphs, etc). These statistics do NOT test your hypothesis.
Inferential statistics are used to test whether the null or alternate hypothesis is supported.You will learn more about these statistics in the next lecture.

Histograms & Bar Charts

Understanding your data type determines how you should visualize it. Two of the most common graphs are histograms and bar charts.

Histograms = continuous data | Bar charts = categorical data

Histogram

  • Used for continuous data (interval and ratio)
  • Used to check normality
  • Must be created for continuous data
  • Bars touch (represent ranges/bins)
  • X-axis: value ranges (bins)
  • Y-axis: frequency

Bar Chart

  • Used for categorical data (nominal and ordinal)
  • Used to compare groups
  • Typically used when 3+ groups
  • Bars do not touch
  • X-axis: categories
  • Y-axis: value or frequency

Checking Normality with Histograms

Inferential statistics depend on whether your continuous data are normally distributed. Choosing the wrong test can lead to invalid conclusions.

Normality does NOT apply to categorical data.

Normal Distribution

A normal distribution is a theoretical pattern that many real-world variables follow (e.g., test scores, height).

  • Mean ≈ Median ≈ Mode
  • Symmetrical shape (mirror image)
  • Bell-shaped curve (most values near center)

Skewness

Skewness refers to how symmetrical a distribution is.

  • Positive skew (right skew): Tail points right, most data on left
  • Negative skew (left skew): Tail points left, most data on right

Kurtosis

Kurtosis describes the shape of the distribution:

  • Leptokurtic: Tall and narrow (too peaked)
  • Mesokurtic: Normal bell shape
  • Platykurtic: Flat and wide

Standard Deviation & Variation

Standard deviation (SD) measures how spread out data are around the mean:

  • Low SD: Data tightly clustered
  • High SD: Data widely spread out

Empirical Rule (68–95–99.7)

  • 68% of data within ±1 SD
  • 95% within ±2 SD
  • 99.7% within ±3 SD
The empirical rule helps estimate where most data points fall in a normal distribution without checking every value.

Even though not all data are perfectly normal, many continuous variables approximate normality, which allows researchers to apply inferential statistics correctly.

TYPES OF DATA

In research, data refers to the information that researchers collect in order to answer questions. The type of data you collect determines how you analyze it and what conclusions you can draw.

There are two primary types of data: quantitative and qualitative. Understanding the difference between these is essential for choosing the correct research methods. Thy type of data determines how it can be analyzed.

Quantitative Data

Quantitative data is numerical data. It involves measurements or quantities that can be analyzed mathematically using statistics. Because this type of data is expressed in numbers, researchers can calculate averages, compare groups, and run statistical tests to draw conclusions. Quantitative data is especially useful for testing hypotheses and identifying patterns or relationships between variables.

Qualitative Data

Qualitative data is descriptive, non-numerical data. It focuses on understanding meaning, experience, or perspective rather than measuring quantities. This type of data is often collected through interviews, open-ended survey responses, or observations.

Instead of statistical analysis, qualitative data is analyzed by identifying patterns, themes, or meanings within the responses.

Quantitative

There are four types of quantitative data, also known as levels of measurement. Being able to correctly identify the level of your variables is essential for choosing the correct analysis.

You must identify the level of measurement to determine:

  • Which descriptive statistics can be calculated
  • Which graphs should be used
  • Which inferential test is appropriate
Level of Measurement Definition Example Data Type
Nominal Categorical data with no rank order. Values are labels or categories only. Race, gender, nationality, state of residence Categorical (Qualitative)
Ordinal Categorical data with a rank order, but the distance between values is not equal. Likert scale responses, restaurant star ratings, Olympic medals Categorical (Qualitative)
Interval Numerical data with equal spacing between values, but no true zero point. Temperature (Celsius or Fahrenheit), psychological scale scores Continuous (Quantitative)
Ratio Numerical data with equal spacing and a true zero point indicating the absence of the variable. Milligrams, kilograms, centimeters, meters Continuous (Quantitative)
