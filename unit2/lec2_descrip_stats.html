Descriptive Statistics

Overview

Descriptive Statistics: These statistics describe and summarize your dataset. This includes commonly known statistics like simple averages, frequencies, and percentages. This also includes less commonly known statistics like standard deviations and normality tests. Descriptive statistics can be displayed numerically (as plain numbers) and visually (as histograms, bar graphs, etc). These statistics do NOT test your hypothesis.
Descriptive Statistic Definition Data Type
Mean the mathematical average of a set of numbers. It is calculated by adding all values and dividing by the number of values. The mean is sensitive to extreme values (outliers), which can pull it upward or downward. Normal, continuous data
Median (Med) The midpoint of a dataset when values are arranged from lowest to highest. If there is an odd number of values, the median is the middle number. If even, it is the average of the two middle numbers.. Abnormal, categorical or continuous data
Mode The most frequently occurring value in a dataset. Categorical data
Standard Deviation (SD) How spread out the data is around the mean. The SD cannot be interpreted without the mean. About 68% of the data fall between −1 standard deviation (SD) and +1 standard deviation (SD) from the mean. Normally distributed, continuous data
Visual Descriptive Data Definition Data Type
Frequency Bar Graph A graph that shows how many times each category occurs in a dataset.Each bar represents a category, and the height of the bar represents the frequency (count) of observations in that category. Categorical data
Histogram A histogram is a graph that shows how numerical data are distributed. It allows you to determine if your data is normally distributed or not. It groups data values into ranges (called bins) and uses bars to show how many observations fall within each range. Taller bars represent ranges that contain more data, while shorter bars represent ranges that contain fewer data. Normal, continuous data

Checking Normality with Histograms

Inferential statistics depend on whether your continuous data are normally distributed. Choosing the wrong test can lead to invalid conclusions.

Normality does NOT apply to categorical data.

Normal Distribution

A normal distribution is a theoretical pattern that many real-world variables follow (e.g., test scores, height).

  • Mean ≈ Median ≈ Mode
  • Symmetrical shape (mirror image)
  • Bell-shaped curve (most values near center)

Skewness

Skewness refers to how symmetrical a distribution is.

  • Positive skew (right skew): Tail points right, most data on left
  • Negative skew (left skew): Tail points left, most data on right

Kurtosis

Kurtosis describes the shape of the distribution:

  • Leptokurtic: Tall and narrow (too peaked)
  • Mesokurtic: Normal bell shape
  • Platykurtic: Flat and wide

Standard Deviation & Variation

Standard deviation (SD) measures how spread out data are around the mean:

  • Low SD: Data tightly clustered
  • High SD: Data widely spread out

Empirical Rule (68–95–99.7)

  • 68% of data within ±1 SD
  • 95% within ±2 SD
  • 99.7% within ±3 SD
The empirical rule helps estimate where most data points fall in a normal distribution without checking every value.

Even though not all data are perfectly normal, many continuous variables approximate normality, which allows researchers to apply inferential statistics correctly.

TYPES OF DATA

There are four types of data, also known as levels of measurement. Being able to correctly identify the level of your variables is essential for choosing the correct analysis.

You must identify the level of measurement to determine:

  • Which descriptive statistics can be calculated
  • Which graphs should be used
  • Which inferential test is appropriate
Level of Measurement Definition Example Data Type
Nominal Categorical data with no rank order. Values are labels or categories and do not have numerical meaning. Race, gender, nationality, state of residence Categorical (Qualitative)
Ordinal Categorical data with a rank order, but the distance between values is not equal. Values can be placed in order, but differences between ranks are not consistent. Likert scale responses, restaurant star ratings, Olympic medals (Gold, Silver, Bronze) Categorical (Qualitative)
Interval Numerical data with equal spacing between values, but no true zero point. Differences between values are meaningful, but ratios are not. Temperature measured in Celsius or Fahrenheit, psychological scale scores Continuous (Quantitative)
Ratio Numerical data with equal spacing and a true zero point. A value of zero indicates the complete absence of the variable, making ratios meaningful. Milligrams, kilograms, centimeters, meters Continuous (Quantitative)
