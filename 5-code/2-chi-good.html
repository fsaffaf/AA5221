Overview

The Chi‑Square Goodness of Fit test is for categorical data only.

It determines whether the observed distribution of one categorical variable matches an expected distribution.

Normality does not apply because categorical data cannot be represented with histograms.

Component Structure Example
Research Question Is the observed distribution the same as the expected distribution? Is the political party distribution of SLU students (2026) the same as in 2025?
Null Hypothesis There is no difference between observed and expected frequencies. There is no difference between observed and expected party frequencies.
Alternate Hypothesis There is a difference between observed and expected frequencies. There is a difference between observed and expected party frequencies.

Step 1: Open Required Packages

library(readxl)
library(ggpubr)

Step 2: Import and Name Dataset

DatasetZ <- read_excel("C:/Users/YourName/Desktop/dataset.xlsx")

Step 3: Create Frequency Table

observed <- table(DatasetZ$PoliticalParty)
observed

Example output: 

Democrat      50
Republican    20
Independent   30

Step 4: Create Bar Chart

barplot(
  observed,
  main = "Political Party",
  xlab = "Political Party",
  ylab = "Count",
  col = rainbow(length(observed))
)

Step 5: Create Expected Data

Expected frequencies must sum to 100%. 

expected <- c(0.40, 0.20, 0.40)

Step 6: Conduct Chi‑Square Goodness‑of‑Fit

chi_result <- chisq.test(x = observed, p = expected)
chi_result

Example output:

X-squared = 12.64, df = 2, p-value = 0.009

Step 7: Calculate Cohen’s W (Effect Size)

w <- sqrt(as.numeric(chi_result$statistic) / sum(observed))
w

Interpretation:

  • 0.10 = weak
  • 0.30 = moderate
  • 0.50+ = strong

Step 8: Interpret and Report Results

# A Chi-Square Goodness of Fit test was conducted to determine if there was a
# difference between observed political party frequencies and expected frequencies.
# There was a statistically significant difference,
# χ²(2) = 12.64, p = .009.
# The effect size was moderate (Cohen's W = .40).
