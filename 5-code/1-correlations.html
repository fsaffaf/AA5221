Pearson & Spearman Correlations

TR CODE

Correlation Overview

  • Correlation allows you to determine the relationship between two continuous variables.
  • Use a Pearson Correlation when both continious variable are normally distributed.
  • Use a Spearman Correlation when one or both continious variable are NOT normally distributed.
  • The Pearson Correlation is a more accurate test than Spearman, so it is the default test when both variables are continuous.
  • However, the Spearman is stil a high-quality backup test when data is not normal.

Step 4: Create a Scatterplot to Visualize the Relationship

Scatterplot Information

  • Scatterplots are required when conducting a correlation.
  • Scatterplots allow you to visually see the relationship between the two continuous variables.
  • Each dot represents one observation (one person).
  • The x-axis (horizontal axis) represents the independent variable.
  • The y-axis (vertical axis) represents the dependent variable.

Directions

Step 5: Interpret the Scatterplot

Directions

Report your observations as comments directly in your R Script.

Relationship Type

Linear Relationship → Dots form a straight-line pattern Non-Linear Relationship → Dots form a curved pattern If the relationship is curved, use Spearman Correlation instead of Pearson Correlation.

Relationship Direction

  • If the line points to the top-right this indicates a positive relationship. This means that as one variable increases, the other variable increases
  • If the line points to the bottom-right this indicates a negative relationship. This means that as one variable increases, the other variable decreases
  • If the line is horizontal, this indicates no relationship
    • . The two variables are not related to each other.

Relationship Strength

Strong Relationship → Dots tightly follow the line Weak Relationship → Dots loosely follow the line No Relationship → Dots appear random

Outliers

Inspect the plot for dots far away from the main cluster. If removing the dots noticeably changes the line of best fit, they may be meaningful outliers.

Report Template

Step 9: Check Normality Statistically (Shapiro-Wilk Test)

Directions

The Shapiro-Wilk test provides a statistical method for objectively testing normality.

Function Breakdown

Code Purpose
shapiro.test() Runs the Shapiro-Wilk normality test.
W = The test statistic used to evaluate normality.
p-value = Determines whether the data is normally distributed.
p-value ≥ .05 → Data is normally distributed p-value < .05 → Data is NOT normally distributed

Code Template

shapiro.test(DatasetName$IndependentVariable) shapiro.test(DatasetName$DependentVariable)

Example Code

shapiro.test(DatasetZ$Age) shapiro.test(DatasetZ$USD)

Example Output

> shapiro.test(DatasetZ$Age) Shapiro-Wilk normality test data: DatasetZ$Age W = 0.959, p-value = 0.754 > shapiro.test(DatasetZ$USD) Shapiro-Wilk normality test data: DatasetZ$USD W = 0.970, p-value = 0.865
