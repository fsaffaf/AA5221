Correlation

Step-by-Step Guide

📊 Overview

Correlation allows you to determine the relationship between two continuous variables.

If the data for both variables is normally distributed, use a Pearson correlation. This is the preferred test because it is more accurate when conditions are met.

If one or both variables are not normally distributed, use a Spearman correlation, which serves as a strong backup test.

Hypothesis Structure

  • Research Question: Is there a relationship between Variable A and Variable B?
  • Null Hypothesis: There is no relationship between the variables.
  • Alternate Hypothesis: There is a relationship between the variables.
Key takeaway: The type of data distribution determines which correlation test you use.

Step 1: Install Required Packages

Install the packages needed to run correlation analyses. Packages only need to be installed once. Running install code repeatedly can cause errors.

The package readxl allows you to import Excel datasets. The package ggpubr allows you to create graphs such as scatterplots. 
install.packages("readxl")
install.packages("ggpubr")
Key takeaway: Install packages once, then load them each session.

Step 2: Load Packages

After installing, load your packages into R. This must be done every time you start a new session. 

library(readxl)
library(ggpubr)
Key takeaway: Installing = one time. Loading = every session.

Step 3: Import Dataset

Import your dataset into RStudio so you can begin analysis.

Make sure your file path correctly points to where your dataset is saved. 
DatasetZ <- read_excel("C:/Users/Username/Desktop/dataset.xlsx")

Once imported, your dataset will appear in the Environment tab and be ready to use.

Key takeaway: Your dataset must be successfully loaded before you can run any analysis.
