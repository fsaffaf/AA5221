Types of Data

Correlation Overview

Correlation allows you to determine the relationship between two continuous variables. Use a Pearson Correlation when both continious variable are normally distributed. Use a Spearman Correlation when one or both continious variable are NOT normally distributed.

The Pearson Correlation is a more accurate test than Spearman, so it is the default test when both variables are continuous. However, the Spearman is stil a high-quality backup test when data is not normal.

Examples

  • Height (e.g., 170 cm)
  • Weight (e.g., 150 lbs)
  • Test scores (e.g., 85%)
  • Number of hours studied

💬 Qualitative Data

Qualitative data is descriptive, non-numerical data. It focuses on understanding meaning, experience, or perspective rather than measuring quantities.

Qualitative data answers questions like: Why? How? What does it mean?

This type of data is often collected through interviews, open-ended survey responses, or observations.

Examples

  • Interview responses about opinions
  • Descriptions of experiences
  • Observations of behavior
  • Written feedback

Instead of statistical analysis, qualitative data is analyzed by identifying patterns, themes, or meanings within the responses.

Key takeaway: Qualitative data = words, meanings, and experiences.

⚖️ Comparing Quantitative and Qualitative Data

Both types of data are useful, but they serve different purposes in research.

Quantitative data provides precision and measurement, while qualitative data provides depth and understanding.
  • Quantitative: Numbers, measurements, statistical analysis
  • Qualitative: Words, meaning, interpretation

Many studies use both types together to get a more complete understanding of a research question.

Final takeaway: Quantitative explains what and how much, while qualitative explains why and how.
