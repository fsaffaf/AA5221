Pearson & Spearman Correlations

TR CODE

Correlation Overview

Correlation allows you to determine the relationship between two continuous variables. Use a Pearson Correlation when both continious variable are normally distributed. Use a Spearman Correlation when one or both continious variable are NOT normally distributed.

The Pearson Correlation is a more accurate test than Spearman, so it is the default test when both variables are continuous. However, the Spearman is stil a high-quality backup test when data is not normal.

Examples

  • Height (e.g., 170 cm)
  • Weight (e.g., 150 lbs)
  • Test scores (e.g., 85%)
  • Number of hours studied

Step 4: Create a Scatterplot to Visualize the Relationship

Directions

Scatterplots are always required when conducting a correlation in order to visually see the relationship between the two variables.

In a scatterplot, each dot represents one observation (one person). The x-axis is the independent (predictor) variable. The y-axis is the dependent (outcome) variable.

Replace the dataset and variable names with your column names.

ggscatter → Creates a scatterplot
x → Specifies the x-axis variable
y → Specifies the y-axis variable
add = "reg.line" → Adds a line of best fit
xlab → Labels the x-axis
ylab → Labels the y-axis

Code Template

ggscatter( DatasetName, x = "IndependentVariable", y = "DependentVariable", add = "reg.line", xlab = "Independent Variable", ylab = "Dependent Variable" )

Example Code

ggscatter( DatasetZ, x = "Age", y = "USD", add = "reg.line", xlab = "Age", ylab = "USD" )

Example Output

image.png

Step 5: Interpret the Scatterplot

Directions

Report what you see in the scatterplot as a comment in your R Script.

Relationship Type

If the dots form a straight-line pattern, the relationship is linear.
If the dots form a curved pattern, the relationship is non-linear and Spearman Correlation should be used.

Relationship Direction

Positive Relationship → The line points upward.
Negative Relationship → The line points downward.
No Relationship → The line is generally horizontal.

Relationship Strength

Strong Relationship → Dots tightly follow the line.
Weak Relationship → Dots loosely follow the line.
No Relationship → Dots appear random.

Outliers

Check for dots far away from the main cluster. If removing them changes the line noticeably, they may be meaningful outliers.

Report Template

# The relationship is [linear / curved]. # The relationship is [positive / negative / does not exist]. # The relationship is [strong / moderate / weak / does not exist]. # There [are / are no] outliers.

Example Report

# The relationship is linear. # The relationship is positive. # The relationship is moderate or strong. # There are no outliers.

Step 9: Check Normality Statistically (Shapiro-Wilk Test)

Directions

The Shapiro-Wilk test is a statistical method used to objectively test normality.

Code Template

shapiro.test(DatasetName$IndependentVariable) shapiro.test(DatasetName$DependentVariable)

Example Code

shapiro.test(DatasetZ$Age) shapiro.test(DatasetZ$USD)

Example Output

> shapiro.test(DatasetZ$Age) Shapiro-Wilk normality test data: DatasetZ$Age W = 0.959, p-value = 0.754 > shapiro.test(DatasetZ$USD) Shapiro-Wilk normality test data: DatasetZ$USD W = 0.970, p-value = 0.865
