Types of Data

Overview

Properly identifying types of data is one of the most important skills in statistics and analytics. A variable's data type determines which statistical techniques, charts, and analyses are appropriate for your data.

Types of Data

Types of data are also known as levels of measurement. Below is a table summarizing the four data types.

Level Definition Examples Data Type
Nominal Categories with no rank order. Race, gender, nationality Categorical
Ordinal Categories can be ranked, but the distance between categories is unknown. Single-item Likert scales Categorical
Interval Equal spacing between values, but no true zero. Temperature (°F, °C), composite Likert scales Continuous
Ratio Equal spacing between values and a meaningful zero point. Weight, height, age, income, distance Continuous

Nominal

Categorizes data into distinct, named groups with no implicit or mathematical order.

Examples

Eye color, gender, political party preference

Ordinal

The most common ordinal-level scale is a single-item Likert measure. A single-item measure asks one specific question. It is simple, efficient, quick to administer, and reduces survey fatigue. However, a single question may not fully capture a complex concept.

Interval

The most common interval-level measure is a multiple-item rating scale. A multiple-item measure uses several related questions to assess the same construct. Researchers typically combine responses by calculating either a sum score or an average score. This type of measurement allows for greater reliability, improved measurement precision, reduced random error, ability to evaluate measurement quality, more stable and consistent results.
