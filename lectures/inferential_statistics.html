Inferential Statistics

Types of Statistics

Statistics can be divided into two main areas: descriptive statistics and inferential statistics. Each serves a different purpose in research.

Descriptive Statistics

Statistics that:

  • Describe the characteristics of a sample.
  • Help determine which inferential statistics should be used.
Inferential Statistics

Statistics that test whether the null hypothesis or alternate hypothesis is supported.

Hypothesis Review

In scientific research, researchers test two competing hypotheses: the null hypothesis and the alternate hypothesis. The way hypotheses are written depends on the research design.

Null Hypothesis

Nothing will happen.

Alternate Hypothesis

Something will happen.

Correlational Study

  • Null: There is NO relationship between Variable 1 and Variable 2.
  • Alternate: There IS a relationship between Variable 1 and Variable 2.

Quasi-Experiment & True Experiment

  • Null: There is NO difference in the scores between Group A and Group B.
  • Alternate: There IS a difference in the scores between Group A and Group B.

Inferential Statistics

When conducting inferential statistics, the composition of your sample is critically important. The accuracy and usefulness of your conclusions depend on how well your sample represents the population you are studying.

For example, imagine your population of interest is 50% male and 50% female, but your collected sample is 80% male and 20% female. Any conclusions drawn from that sample may not accurately reflect the population because the sample is biased and unrepresentative.

The study of how samples are selected and how representative they are is called sampling theory. Although sampling theory is a complex topic, it is essential for ensuring that inferential statistics are valid and reliable.

How Inferential Statistics Work

Inferential statistics are used to test hypotheses. They are called inferential statistics because researchers draw inferences from data.
There are many inferential tests. The test selected depends on:
  • Research design
  • Variable type
  • Data distribution
Regardless of which inferential test is used, all inferential tests produce a probability value called a p-value.
The p-value is used to determine whether the null hypothesis or alternate hypothesis is supported.

P-Value

P-Value

The "p" stands for probability. The p-value represents the likelihood that the observed results could occur if the null hypothesis were true.

The p-value ranges from 0 to 1 (0% to 100%).

  • The closer the p-value is to 0, the more support there is for the alternate hypothesis.
  • The closer the p-value is to 1, the more support there is for the null hypothesis.

Alpha Value (α)

Alpha Value (α)

The Greek letter alpha (α) serves as the benchmark used to interpret p-values. The most common alpha level is .05 (5%).

Researchers compare obtained p-values to established alpha levels.

Common alpha levels include:

  • .05
  • .01
  • .001

Throughout this course, we will use α = .05.

Statistical Significance

Statistical Significance

Statistical significance occurs when the obtained p-value is less than the selected alpha value.

Achieving statistical significance means the alternate hypothesis is supported.

When p ≥ .05

If the p-value is greater than or equal to .05, there is at least a 5% probability that the null hypothesis could explain the results.

The results are NOT statistically significant, and the null hypothesis is supported.

When p < .05

If the p-value is less than .05, there is less than a 5% probability that the null hypothesis explains the results.

The results ARE statistically significant, and the alternate hypothesis is supported.

Examples
  • Statistically Significant: p = 0.01234
  • Not Statistically Significant: p = 0.1234

Effect Size

Effect Size

An effect size is a statistic calculated after the alternate hypothesis is supported. It tells researchers how strong a relationship is or how large a group difference is.

Statistical significance tells us if something happened. Effect size tells us how important it is.

  • For correlational studies, effect size describes how strong the relationship is between variables.
  • For quasi-experiments and true experiments, effect size describes how large the difference is between groups.

Each inferential statistic has its own corresponding effect size measure.

Effect size should only be calculated and reported when results are statistically significant. If results are not statistically significant, effect size does not need to be calculated.

Putting It All Together

Results Plain English Hypothesis Supported Reporting Effect Size
p ≥ .05 The p-value is equal to or greater than .05. The null hypothesis is supported. The results are NOT statistically significant. Do not calculate effect size.
p < .05 The p-value is less than .05. The alternate hypothesis is supported. The results ARE statistically significant. Calculate effect size.

Key Takeaway

Inferential statistics allow researchers to test hypotheses using sample data. Researchers interpret p-values by comparing them to an alpha level. When results are statistically significant, the alternate hypothesis is supported and effect size should be calculated to determine the practical importance of the findings.
