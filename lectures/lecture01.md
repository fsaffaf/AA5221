# Lecture 1: Introduction to R and RStudio

## Overview
RStudio is widely used across industries for data analysis and visualization. It integrates with tools such as Python, SPSS, Excel, Microsoft Word, and PowerPoint. It is free, open source, and supports reproducible and shareable workflows.

## Programming Concepts

| Term | Definition |
|-----|------------|
| **Computer Programming Language** | A language used to tell a computer what tasks to perform (e.g., Python, Java, R). |
| **R Programming Language** | A language designed for statistical computing and data analysis. |
| **Syntax** | The rules that govern how instructions must be written. |
| **Code** | Written instructions created using a programming language. |

## R Systems and Tools

| Term | Definition |
|-----|------------|
| **R Platform (Old)** | Original console-only environment for R. |
| **RStudio (New)** | Integrated environment for writing code, viewing data, and visualizing graphics. |
| **Base R** | Core functions included by default. |
