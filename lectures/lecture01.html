Overview

RStudio is widely used across industries for data analysis and visualization. It integrates with tools such as Python, SPSS, Excel, Microsoft Word, and PowerPoint. It is free, open source, and supports reproducible and shareable workflows.

💡

Programming Concepts

Term Definition
Computer Programming Language A language used to tell a computer what tasks to perform. Examples include Python, Java, C++, and R.
R Programming Language A language designed for statistical computing and data analysis.
Syntax The rules that govern how instructions must be written.
Code Written instructions created using a programming language.
🛠️

R Systems and Tools

Term Definition
R Platform (Old) The original R interface consisting only of a console.
RStudio (New) A user‑friendly interface for writing code, viewing data, and visualizing results.
Base R The core set of functions included with R by default.
Package A collection of pre‑written functions that extend R’s capabilities.
🧬

Data Types

Term Definition
Numerical Continuous numeric data.
Factor Categorical data stored as labels.
🧭

Workflow and Interface

Term Definition
Comments Lines beginning with # that explain code.
R Markdown (.Rmd) A file combining R code, output, and narrative text.
Source Panel Where scripts are written, edited, and saved.
Console Executes code interactively and displays output.
Environment Displays variables and objects in memory.
Plot Pane Displays graphical output and plots.
