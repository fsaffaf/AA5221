Overview

RStudio is widely used across industries for data analysis and visualization. It integrates with tools such as Python, SPSS, Excel, Microsoft Word, and PowerPoint. It is free, open source, and supports reproducible and shareable workflows.

 

Programming Concepts

TERM DEFINITION
Computer Programming Language A language used to tell a computer what tasks to perform. Examples include Python, Java, C++, and R. Like spoken languages, programming languages have their own rules and conventions.
R Programming Language The set of formal rules that define how the R programming language is written and interpreted. These rules govern keywords, punctuation, spacing, and structure.
Syntax The specific rules of a programming language. Every programming language has its own syntax. If syntax is incorrect, the program cannot read or understand the instructions.
Code The written instructions created using a programming language. In R, code is commonly written for data analysis, statistical computing, and visualization.

R Systems and Tools

TERM DEFINITION
R Platform (Old) The original form of R. It consists only of a console where users type code. It does not allow users to easily view data or graphics.
RStudio (New) A user-friendly interface for using R. It allows users to write code, view data, and visualize graphics all in one place.
Base R The core set of functions available in R by default, without installing additional packages.
Package A bundle of pre-written functions that adds extra tools to the basic R program. Packages let you do specific tasks—like reading Excel files, making charts, or running statistical tests—without having to write all the code yourself. Packages make R more powerful and easier to use by providing ready-made tools for many tasks. R does not install all packages automatically because there are thousands available, many of which serve specialized statistical tasks across different fields, such as biology, psychology, or chemistry—tasks that not every user will need. By allowing users to choose which packages to install, R ensures that your setup is tailored to your specific needs, avoids unnecessary “bloatware,” and conserves system resources like memory (RAM) and processing power (CPU).

Data Types

TERM DEFINITION
Numerical The R programming term for a continuous variable.
Factor The R programming term for a categorical variable.

Workflow and Interface

TERM DEFINITION
Comments In R, lines that begin with a hashtag (#) are treated as comments.
R Markdown File (.Rmd) A plain text file that combines R code, output, and written commentary into a single reproducible document.
Source Panel Write and save code scripts. Used for writing, editing, saving, and re-opening R code files. Allows code to be run line by line or in chunks (e.g., Ctrl + Enter)
Console Run code interactively and see results. Displays code output such as numerical results. Code typed directly here is not saved.
Environment View available variables. Located in the top-right. Displays defined variables, data sets, and other objects currently stored in memory.
Plot Pane Tabs for Help, Packages, and Plots. Displays visual outputs such as histograms. Users can navigate between plots using the left and right arrows.

  • To save your script file, click File > Save (or Ctrl + S)

  • Shows all variables (independent variable, dependent variable, etc).

3:57  How to Use the Plot Pane
  • Plots tab:
    • Displays plots you have created.
    • Navigate previous plots with arrows.
  • Help tab:
    • Shows documentation for functions using ?function.
    • Example: ?print displays details about print().
  • Packages tab: Install and load R libraries.
    • Example: Install psyc package via Install button and search.
    • Highlights R’s power through thousands of specialized libraries
