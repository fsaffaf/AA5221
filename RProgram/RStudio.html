Installing R and RStudio

Overview

R is a free, open-source programming language used for data analysis, statistics, and visualization. RStudio is an integrated development environment (IDE) that provides a user-friendly interface for working with R.

Personal Laptops

Install R
  1. Visit the CRAN website: https://cran.r-project.org/
  2. Select your operating system (Windows, macOS, or Linux).
  3. Download the latest version of R.
  4. Run the installer and accept the default settings.
  5. Open R after installation to confirm it launches successfully.
Install RStudio
  1. Visit the Posit download page: https://posit.co/download/rstudio-desktop/
  2. Download the free RStudio Desktop version.
  3. Run the installer and follow the installation prompts.
  4. Open RStudio after installation.
  5. Verify that RStudio detects your R installation automatically.
Verify Installation

Enter the following command in the RStudio Console:

2 + 2

Using Apporto
Students using a Saint Louis University-issued laptop cannot install R or RStudio locally. Instead, use RStudio through Apporto.
Step 1: Open Apporto

If you have a SLU-issued Mac, Apporto may not work properly in Safari. Please use Google Chrome.

In Canvas, click the Apporto page from the navigation menu on the left side of the course.

The tab will appear alongside Home, Announcements, Syllabus, and other course links.
