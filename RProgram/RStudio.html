Installing R and RStudio

Learning Objectives
  • Install the R programming language on your computer.
  • Install the RStudio integrated development environment (IDE).
  • Verify that both programs are working correctly.
  • Access additional resources and installation tutorials.

What Are R and RStudio?

R is a free, open-source programming language widely used for statistical analysis, data visualization, and data science.

RStudio is an integrated development environment (IDE) that makes working with R easier by providing a user-friendly interface for writing code, viewing plots, managing files, and creating reports.

You must install R first and then install RStudio.

Step 1: Install R

  1. Visit the Comprehensive R Archive Network (CRAN):
    https://cran.r-project.org/ https://cran.r-project.org/
  2. Select your operating system:
    • Windows
    • macOS
    • Linux
  3. Download the most recent version of R for your operating system.
  4. Run the installer and accept the default installation options unless instructed otherwise.
  5. After installation is complete, open R to confirm that it launches successfully.

Step 2: Install RStudio

  1. Visit the Posit (formerly RStudio) download page:
    https://posit.co/download/rstudio-desktop/ https://posit.co/download/rstudio-desktop/
  2. Download the free RStudio Desktop version.
  3. Run the installer and follow the installation instructions.
  4. Open RStudio after installation.
  5. Verify that RStudio automatically detects your R installation.

Verify Your Installation

Once RStudio is open, enter the following command in the Console: 

2 + 2

If your installation is working correctly, RStudio should return: 

[1] 4

Congratulations! You are ready to begin using R and RStudio.

Common Issues and Solutions

Issue Possible Solution
RStudio cannot find R Install R first, then restart and reinstall RStudio if necessary.
Installation fails Download the latest installer and run it with administrator privileges.
RStudio opens but displays errors Update both R and RStudio to their latest versions.
