RStudio Layout

Overview

RStudio is a free program used for data analysis and visualization. It allows you to write, run, save, and share R code.

RStudio is divided into several panes. Each pane has a different purpose.

RStudio User Interface

The video linked below provides a brief introduction to the RStudio interface. As you begin working with R, you will primarily use four areas: the Source, Console, Environment, and Plots panes.

Major RStudio Panes

The four panes listed below are the areas you will use most frequently throughout this course when writing code, viewing results, and creating graphs.
Pane Location Purpose
Source Top Left This is where you write and save your R code. Your R Script stores the instructions you give R so that you can run them again later.
Console Bottom Left This is where R runs your code and displays results and messages. Code entered directly into the Console is not automatically saved.
Environment Top Right This area shows the objects currently stored in R's memory, such as datasets, variables, and tables that you create.
Plots Bottom Right This is where R displays graphs and charts that you create. This area also contains tabs for tools such as Help and Packages.

Key Takeaway

Think of RStudio as your workspace. You write code in the Source, run code in the Console, view objects in the Environment, and see graphs in the Plots pane. Understanding the purpose of each pane will make it much easier to follow course demonstrations, complete assignments, and troubleshoot your code.
