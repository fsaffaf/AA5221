Installing R and RStudio

Learning Objectives
  • Install the R programming language on your computer.
  • Install RStudio Desktop.
  • Verify that your installation is working properly.
  • Access additional installation resources.

Overview

R is a free, open-source programming language used for data analysis, statistics, and visualization. RStudio is an integrated development environment (IDE) that provides a user-friendly interface for working with R.

Important: Install R first, then install RStudio. RStudio requires an existing R installation.

Installation Instructions

Step 1: Install R

  1. Visit the CRAN website: https://cran.r-project.org/ https://cran.r-project.org/
  2. Select your operating system (Windows, macOS, or Linux).
  3. Download the latest version of R.
  4. Run the installer and accept the default settings.
  5. Open R after installation to confirm it launches successfully.

Step 2: Install RStudio

  1. Visit the Posit download page: https://posit.co/download/rstudio-desktop/ https://posit.co/download/rstudio-desktop/
  2. Download the free RStudio Desktop version.
  3. Run the installer and follow the installation prompts.
  4. Open RStudio after installation.
  5. Verify that RStudio detects your R installation automatically.

Verify Your Installation

Enter the following command in the RStudio Console: 

2 + 2

You should see: 

[1] 4

If this output appears, your installation is working correctly.

Troubleshooting

Issue Solution
RStudio cannot find R Install R first, then restart or reinstall RStudio.
Installation fails Download the latest installer and run it as an administrator.
RStudio opens with errors Update both R and RStudio to the latest versions.
