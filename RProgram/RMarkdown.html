Microsoft OneDrive

Overview

In this course, Microsoft OneDrive is used to organize coding assignment files and provide access to submitted work.

What is Microsoft OneDrive?

Microsoft OneDrive is Microsoft's cloud storage service. It allows you to store files online, access them from multiple devices, and share documents with others.

Important: Do NOT use Google Drive for course submissions. Google Drive is a separate cloud storage system. All course files should be stored and shared through Microsoft OneDrive.

Why is Digital File Organization Important?

Effective file organization is an essential skill in both academic and professional settings. Organizing files into clearly labeled folders helps you quickly locate documents, prevent lost work, and maintain a logical structure for projects and assignments.

File organization becomes especially important when working with multiple versions of documents, submitting assignments, or collaborating with others.

Professional File Organization Practices

  • Create folders with clear and descriptive names.
  • Keep related files together in the same location.
  • Avoid storing important course files only on your personal computer.
  • Use consistent naming conventions for assignments and projects.
  • Share files using appropriate permissions.
  • Use shared cloud storage to share the most current version of a file without repeatedly sending email attachments.

What is Cloud Storage?

Simple Definition: Files can be stored using local storage or cloud storage.
Topic Local Storage Cloud Storage
Where are files stored? On your computer, USB drive, flash drive, or external hard drive. On secure internet-based servers.
How do you access them? Directly from the device where they are stored. From multiple devices by signing in and connecting to the internet.
If the device is lost or damaged You may lose access to your files. Your files remain available online.
Think of it Like... Keeping important documents in your home. Keeping important documents in a secure bank vault.
Example Saving your R files only on your computer. Saving your R files to Microsoft OneDrive.
Final Point Your files depend on a single physical device. Your files remain accessible from multiple devices.

Key Takeaway

Microsoft OneDrive helps protect your work, keeps files organized, and allows you to access your assignments from multiple devices.

Developing good file organization habits now will make coursework easier and prepare you for professional environments where cloud storage and digital collaboration are standard practice.
