R Scripts

Overview

An R script is a digital instruction sheet that tells a computer how to analyze information and generate results automatically. You will write R Script files to analyze data throughout this course.

R Script Files

An R Script file is a text file containing a series of instructions written in the R programming language. These instructions tell the computer how to work with data, perform calculations, create visualizations, and generate reports.

An R Script can automate many tasks involved in data analysis, including:

  • Add and calculate numerical values
  • Analyze survey, experimental, or research data
  • Create graphs and visualizations
  • Clean and organize datasets
  • Generate reports automatically
  • Identify patterns and predict trends

R is widely used by researchers, professors, statisticians, scientists, and business analysts because it is specifically designed for statistical computing and data analysis.

Why Use R Scripts?

Key Idea: R Scripts make data analysis faster, more consistent, and easier to reproduce.

Once a script is created, it can be reused whenever new data become available, ensuring the same analysis is performed the same way each time.

An R Script makes your data analysis easily reproducible.

Think about creating a graph in Excel. If your dataset changes, you may need to update formulas, recreate charts, and repeat several steps manually. Similarly, in programs such as SPSS, JASP, or Minitab, you often perform analyses by clicking through menus each time.

An R Script works differently. It saves every step of the analysis as code. This gives you:

  1. A clear record of how the data was analyzed
  2. The ability to reanalyze an updated dataset with the click of a single button ("re-run all analyses")
  3. The ability to fix a single error, edit one line of code, and rerun the analysis
  4. The ability to save your work midway through an analysis and continue later

This can reduce a process that might take hours of clicking to just a few seconds.

Script Pane vs. Console

When working in RStudio, it is important to understand the difference between the Script Pane and the Console.

Location Purpose
Script Pane The area where you write, edit, organize, and save your R code. Scripts can be reopened, shared, and reused.
Console Pane The area where R executes code and displays results, warnings, and error messages. Code typed directly into the Console is not saved.

Key Takeaway

Write and save code in the Script Pane. Run code and view results in the Console. Always save important work in an R Script because code entered directly into the Console will disappear when RStudio is closed.

Learning to organize your work in R Scripts will make your analyses easier to reproduce, edit, share, and rerun throughout the course and beyond.
