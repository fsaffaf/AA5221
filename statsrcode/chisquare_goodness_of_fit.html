Chi-Square Goodness of Fit test

Prepare
Overview of the Test

The Chi-Square Goodness-of-Fit test is used for categorical data only.

It allows you to determine whether the distribution of one categorical variable matches an expected distribution.

In this context, distribution refers to how participants are distributed across the categories of a variable. Normality does not apply because the data are categorical counts rather than continuous scores.

The research design is observational. Therefore, there is no independent variable (IV) and no dependent variable (DV).

Component General Structure Example
Research Question Is the current frequency distribution of the variable the same as the expected frequency distribution? Is the current frequency distribution of SLU students across the Madrid, North, and South campuses (2026) the same as the previous year (2025)?
Null Hypothesis There is no difference between the observed and expected frequencies. There is no difference between the observed campus frequencies and the expected frequencies.
Alternative Hypothesis There is a difference between the observed and expected frequencies. There is a difference between the observed campus frequencies and the expected frequencies.

The Chi-Square Goodness-of-Fit test compares the frequencies observed in a dataset to frequencies that are expected based on historical data, previous research, or a theoretical expectation.

Example Expected Distribution

  • 10% Madrid
  • 60% North
  • 30% South

These percentages become the expected proportions used in the analysis.

Important: Expected proportions must always add up to 100% (1.00).

Assumptions

  • Each observation is independent (each participant appears once).
  • Categories are mutually exclusive (each participant fits in exactly one category).
  • Every expected count is 5 or more. You will check this in Step 5.

RScript Code Template

Below is an example of what your code will look like. Your code will be different because the dataset name, variable name, expected proportions, results, and interpretations will depend on your assigned dataset.

library(readxl)

data2026 <- read_excel("C:/Users/John/OneDrive/Documents/AA5221/Datasets/campus_data.xlsx")

observed <- table(data2026$campus)
observed

barplot(observed,
main = "Campus",
xlab = "Campus",
ylab = "Frequency",
col = rainbow(length(observed)))

expected <- c(Madrid = .10, North = .60, South = .30)
names(observed)
sum(expected)

chi_result <- chisq.test(x = observed, p = expected)
chi_result
chi_result$expected

w <- sqrt(as.numeric(chi_result$statistic) / sum(observed))
w

# A Chi-Square Goodness-of-Fit test was conducted to determine if there was a difference between the observed campus frequencies and the expected frequencies.

# The difference was large (Cohen's W = 1.34).

Step 3
Create a Frequency Table

A frequency table summarizes how many observations belong to each category of a categorical variable. The frequency table will provide the observed frequencies used in the Chi-Square Goodness-of-Fit test.

Understanding Observed Frequencies

The values in the frequency table are called observed frequencies. These are the actual category counts found in your dataset.

The Chi-Square Goodness-of-Fit test compares:

  • Observed Frequencies → What you found in your dataset.
  • Expected Frequencies → What you expected to find based on previous research, theory, or historical data.

Understanding Bar Charts

Bar charts are appropriate for categorical variables because each category represents a distinct group.

  • Each bar represents one category.
  • The height of the bar represents the frequency (count).
  • Bars are separated because categories are distinct groups.
  • The chart allows you to visually inspect the distribution of the variable.

Step 5
Conduct the Chi-Square Goodness of Fit Test

The Chi-Square Goodness-of-Fit test compares the frequencies observed in your dataset to frequencies that were expected based on prior research, historical data, or a theoretical expectation.

Before conducting the test, you must create a vector containing the expected proportions.

Create the Expected Proportions

  1. Return to the research scenario provided with your assignment.
  2. Locate the expected percentages for each category.
  3. Convert each percentage to a decimal.
  4. Enter the decimals into a vector named expected.
  5. Ensure the order of the expected proportions matches the order of the categories shown in your frequency table.

Code Template

Copy-and-paste the code into your R Script. Replace the category names with the names shown in your frequency table, and replace each prop with the expected proportion for that category. 

expected <- c(category1 = prop1, category2 = prop2, category3 = prop3)

Order Matters

The expected proportions must appear in the same order as the categories displayed in your frequency table. R does not match proportions to categories by name, so a wrong order will produce wrong results without any warning.

Suppose your frequency table displays:

Madrid
North
South

Then your expected proportions must follow the same order.

expected <- c(Madrid = .10, North = .60, South = .30)
  • 10% Madrid → 0.10
  • 60% North → 0.60
  • 30% South → 0.30

Check Your Setup

Run these two lines. The names should match the order of your expected vector, and the sum should be 1.

names(observed)
sum(expected)

Important: Expected proportions must add up to 1.00 (100%).

Why is there no output for the expected line?

Running the expected line of code will not produce any output. That is normal.

Conduct the Chi-Square Goodness-of-Fit Test

Once the observed frequencies and expected proportions have been created, use the chisq.test() function to perform the analysis. Copy-and-paste the text below into your R Script. 

chi_result <- chisq.test(
x = observed,
p = expected)

chi_result

The first line performs the Chi-Square Goodness-of-Fit test. The second line displays the results.

Output

	Chi-squared test for given probabilities

data:  observed
X-squared = 178.33, df = 2, p-value < 2.2e-16

  • X-squared (χ²) = The Chi-Square test statistic. Larger values indicate greater differences between the observed and expected frequencies.
  • Degrees of Freedom (df) = Used to determine the sampling distribution for the test. For a Goodness-of-Fit test: df = Number of Categories − 1.
  • P-Value = Used to determine whether the result is statistically significant. Very small p-values are displayed as a limit (for example, < 2.2e-16) or in scientific notation. Report any p-value below .001 as p < .001.
P-Value Decision Conclusion
p ≤ .05 Statistically Significant The observed frequencies differ from the expected frequencies.
p > .05 Not Statistically Significant The observed frequencies do not differ enough from the expected frequencies to conclude that a real difference exists.

Check the Expected Counts

The test is only trustworthy when every expected count is 5 or more. Run the line below and confirm that every value is at least 5.

    Madrid  North  South 
        10     60     30

Step 6
Calculate the Cohen's W (Effect Size)

For Chi-Square Goodness-of-Fit tests, the effect size is Cohen's W.

Cohen's W describes the magnitude of the difference between the observed and expected distributions.

Calculate Cohen's W

Copy-and-paste the following code into your R Script.

w <- sqrt(as.numeric(chi_result$statistic) / sum(observed))
w

The first line calculates Cohen's W. The second line displays the result.

Output

[1] 1.335415

Rounded to two decimal places, this is 1.34. Unlike many effect sizes, Cohen's W can exceed 1 when the observed and expected distributions are very different. This value represents the magnitude of the discrepancy between the observed and expected frequencies.

Interpreting Cohen's W

Use the table below to classify the size of the effect.

Cohen's W Interpretation
Less than 0.10Negligible Difference
0.10 to less than 0.30Small Difference
0.30 to less than 0.50Moderate Difference
0.50 or HigherLarge Difference
