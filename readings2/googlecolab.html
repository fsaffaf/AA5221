Google Colab

What Is Google Colab?

Google Colab (short for Google Colaboratory) is a free, web-based tool that allows you to write and run Python code in your internet browser. You do not need to install Python or other programming software on your computer.

How Does It Work?

Google Colab uses notebooks. A notebook contains different types of cells:

  • Text cells: Display instructions, explanations, and questions.
  • Code cells: Run Python code and display the results.
For This Course: For this course, you will use Google Colab notebooks to complete assignments, follow instructions, answer questions, and learn basic data analysis concepts.

How Do I Access Google Colab?

  1. Open your internet browser.
  2. Go to Google Colab.
  3. Sign in with your Google account if prompted.
  4. Open the notebook linked in your course.
  5. Save your own copy to Google Drive before completing the assignment.

How Do I Complete an Assignment?

  1. Read the instructions in each section.
  2. Type your answers wherever the notebook asks you to respond.
  3. If a code cell is provided, run it by clicking the play button next to the cell.
  4. Review your work and make sure you have answered every question.
  5. Rename your notebook as instructed in the assignment.
  6. Share your completed notebook with your instructor using the course sharing instructions.

What Do I Need to Know?

  • You do not need to install Python on your computer.
  • You can access your notebook through an internet browser.
  • Your work can be saved in Google Drive.
  • You can return to your notebook later to continue working.
  • Always work in your own copy of the assignment.

Need Help?

Visit the Google Colab website to access your notebooks. Follow the instructions in each course assignment, and contact your instructor if you have trouble accessing or sharing your work.
