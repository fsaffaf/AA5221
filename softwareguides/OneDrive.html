How to Create and Share a OneDrive Folder

Microsoft OneDrive

Overview

In this course, Microsoft OneDrive is used to organize coding assignment files and provide access to submitted work. Microsoft OneDrive helps protect your work, keeps files organized, and allows you to access your assignments from multiple devices. Developing good file organization habits now will make coursework easier and prepare you for professional environments where cloud storage and digital collaboration are standard practice. Microsoft OneDrive is Microsoft's cloud storage service. It allows you to store files online, access them from multiple devices, and share documents with others.

Important: Do NOT use Google Drive for course submissions. Google Drive is a separate cloud storage system. All course files should be stored and shared through Microsoft OneDrive.

What is Cloud Storage?

Simple Definition: Files can be stored using local storage or cloud storage.
Topic Local Storage Cloud Storage
Where are files stored? On your computer, USB drive, flash drive, or external hard drive. On secure internet-based servers.
How do you access them? Directly from the device where they are stored. From multiple devices by signing in and connecting to the internet.
If the device is lost or damaged You may lose access to your files. Your files remain available online.
Think of it Like... Keeping important documents in your home. Keeping important documents in a secure bank vault.
Example Saving your R files only on your computer. Saving your R files to Microsoft OneDrive.
Final Point Your files depend on a single physical device. Your files remain accessible from multiple devices.

Why is Digital File Organization Important?

Effective file organization is an essential skill in both academic and professional settings. Organizing files into clearly labeled folders helps you quickly locate documents, prevent lost work, and maintain a logical structure for projects and assignments.

File organization becomes especially important when working with multiple versions of documents, submitting assignments, or collaborating with others.

Professional File Organization Practices

  • Create folders with clear and descriptive names.
  • Keep related files together in the same location.
  • Avoid storing important course files only on your personal computer.
  • Use consistent naming conventions for assignments and projects.
  • Share files using appropriate permissions.
  • Use shared cloud storage to share the most current version of a file without repeatedly sending email attachments.
Create and Share a OneDrive Folder
Why are you doing this?
You can use a OneDrive folder to keep your course files organized and share your work with your instructor or classmates when needed.
Step 1: Open OneDrive

Open OneDrive

  1. Sign in to your SLU Microsoft 365 account.
  2. Open OneDrive.
  3. You should see your OneDrive files and folders.
Step 2: Create a New Folder

Create Your Folder

  1. In OneDrive, select New.
  2. Select Folder.
  3. Enter a name for your folder.
  4. Select Create.
Example Folder Name
AA 5221 Assignment 5

Use a clear folder name so you can easily find your files later.

Step 3: Add Your Files

Upload or Move Files Into the Folder

Open your new folder and add the files you want to keep together.

  1. Open the folder you created.
  2. Select Add new or Upload.
  3. Select Files.
  4. Choose the file or files from your computer.
  5. Wait for the files to finish uploading.
Tip: Keep all files related to the same assignment in the same folder. This makes it easier to find and share your work.
Step 4: Share the Folder

Share Your Folder

  1. Find the folder you want to share.
  2. Right-click the folder or select the Share button.
  3. Enter the person's SLU email address.
  4. Choose the appropriate permission.
Can edit
The person can open, edit, add, and delete files in the shared folder.
Can view
The person can open and view the files but cannot make changes.

For most course assignments, use the permission specified in your assignment instructions.

Step 5: Send the Share Invitation

Send the Invitation

  1. Confirm that the correct email address is entered.
  2. Confirm that the correct permission is selected.
  3. Add a message if needed.
  4. Select Send.

The person you shared the folder with will receive an email with access to the folder.

Step 6: Copy a Share Link

Copy the Folder Link

You can also share the folder by copying a link.

  1. Right-click the folder or select Share.
  2. Select Copy link.
  3. Check the link settings before copying the link.
  4. Make sure the person receiving the link has the appropriate access.
  5. Select Copy.
  6. Paste the link into your assignment submission, email, or message as instructed.
Important: Test your link before submitting it. Open the link in a private or incognito browser window if possible. Make sure you can access the folder with the permissions you intended to provide.
