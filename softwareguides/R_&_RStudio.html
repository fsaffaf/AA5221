R & RStudio

Overview

R is a free, open-source programming language used for data analysis, statistics, and visualization. RStudio is an integrated development environment (IDE) that provides a user-friendly interface for working with R.

Using RStudio on Personal Laptops

Install R
  1. Visit the CRAN website: CRAN.
  2. Select your operating system: Windows, macOS, or Linux.
  3. Download the latest version of R.
  4. Run the installer and accept the default settings.
  5. Open R to confirm that it launches successfully.
Install RStudio
  1. Visit the Posit RStudio Desktop download page.
  2. Download the free RStudio Desktop version.
  3. Run the installer and follow the installation prompts.
  4. Open RStudio after installation.
  5. Verify that RStudio detects your R installation.
Verify Installation

Enter this command in the RStudio Console:

2 + 2

You should see:

[1] 4

The Four RStudio Panes

RStudio is divided into several panes that help you write code, manage files, view output, and explore data. Understanding the purpose of each pane will make it easier to work efficiently.

Review the image and table below to become familiar with the RStudio interface.

Pane Purpose
Source Used to create, edit, and save R scripts, R Markdown files, and other project files. This is where you write, organize, and save your R code. Scripts can be reopened, shared, and reused.
Console Executes R code and displays text results, warnings, and error messages. Code typed directly into the Console is not automatically saved in a script.
Environment Displays objects currently stored in memory, including variables, data frames, functions, and other R objects created during a session.
Output / Files / Plots / Packages / Help The lower-right pane contains tabs for browsing files, viewing generated plots, managing packages, and accessing function documentation. The exact tabs depend on your RStudio configuration.

Source Pane File Types

Two important file types you will use in the Source pane are R Script (.R) and R Markdown (.Rmd).

Feature R Script (.R) R Markdown (.Rmd)
Main Purpose Write and execute R code. Create a report combining code, results, and written explanations.
Contains Primarily R code and comments. Code, text, tables, graphs, and interpretation.
Output Results appear in the Console or Plots pane. Can generate a formatted report, such as an HTML document.
Sharing Others generally need the script, the data, and a compatible R environment to rerun the analysis. A knitted HTML report can be viewed in a browser without installing R or RStudio. Reproducing the analysis still requires the source file and data.

R Script Files

An R Script is a text file containing instructions written in the R programming language. These instructions tell the computer how to work with data, perform calculations, create visualizations, and conduct statistical analyses.

R Scripts make data analysis faster, more consistent, and easier to reproduce. Once a script is created, it can be reused whenever new data become available, helping ensure that the same analysis is performed the same way each time.

An R Script makes your data analysis reproducible.

Think about creating a graph in Excel. If your dataset changes, you may need to update formulas, recreate charts, and repeat several steps manually. Similarly, in programs such as SPSS, JASP, or Minitab, you may perform analyses by clicking through menus each time.

An R Script saves the analysis steps as code. This gives you:

  1. A clear record of how the data were analyzed.
  2. The ability to rerun analyses on updated data without repeating every step manually.
  3. The ability to fix an error, edit a line of code, and rerun the analysis.
  4. The ability to save your work and continue later.

A reproducible script can reduce repeated manual work from hours to seconds.

R Markdown

An R Script can perform a full set of analyses with the click of a button. However, the script may also require access to the original dataset and any other files used in the analysis.

An R Markdown document communicates the research process by combining code, results, and written explanations into one reproducible report.

The purpose of converting an R Script into R Markdown is not simply to run code. It is to create a complete, readable report that helps another person understand your analysis from beginning to end.

How to Create an R Markdown Report

Follow these steps to organize your statistical analyses and create a shareable HTML report.

Step 1: Install the R Markdown Package

Before creating an R Markdown document, install the rmarkdown package if it is not already available.

Run this installation command once:

install.packages("rmarkdown")

After installation, load the package when you need it: 

library(rmarkdown)

Do not reinstall the package every time you open RStudio. Installation and loading are different tasks.

Step 2: Create a New R Markdown File

In RStudio, select:

File → New File → R Markdown

A window will appear asking for information about your document.

Setting What to Enter
Title Enter your assignment or project title, such as Assignment 1.
Author Enter your name.
Output Format Select HTML.

Click OK. A new R Markdown file will open.

RStudio automatically creates a sample document. Remove the example text and code before beginning your assignment.

Step 3: Copy Code from Your R Script

R Markdown documents contain two main types of content:

Content Type Purpose
Narrative Text Written explanations describing the methods, results, and interpretations.
Code Chunks R code that performs calculations, creates graphs, and produces output.

Copy the analysis code from your existing .R script and paste it into your new .Rmd file. You will need to place the code inside code chunks.

Step 4: Convert Your R Script to R Markdown Format

An R Script and an R Markdown document use different formatting rules. When transferring code, separate your explanations from your R code.

Outside code chunks: Written explanations, instructions, and interpretations.

Inside code chunks: R code that will be executed by the program.

Converting Comments into Written Text

In an R Script, comments begin with the # symbol. Comments are notes for yourself and are ignored by R when the code runs.

In R Markdown, explanations should usually be written as regular text rather than as R comments.

R Script R Markdown 
# Calculate descriptive statistics
 Calculate descriptive statistics.

Creating Code Chunks

R code must be placed inside a code chunk so that R Markdown knows which instructions to execute.

A code chunk begins with three backticks followed by {r}. It ends with three backticks on a separate line. 

```{r}
2 * 2
```

When you knit the document, R executes the code chunks and includes their results in the report.

Step 5: Knit the HTML Report

Save your R Markdown file using the .Rmd extension.

  1. Save the document.
  2. Click the Knit button in RStudio.
  3. Select HTML if RStudio asks for an output format.
  4. Review the generated report for errors and missing results.
  5. Save and submit the required files according to your assignment instructions.
Important: If knitting fails, read the error message. Check that your code chunks are formatted correctly, required packages are available, and your data files can be found by the document.
