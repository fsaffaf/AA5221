R & RStudio

Overview

R is a free, open-source programming language used for data analysis, statistics, and visualization. RStudio is an integrated development environment (IDE) that provides a user-friendly interface for working with R.

Personal Laptops

Install R
  1. Visit the CRAN website: https://cran.r-project.org/
  2. Select your operating system (Windows, macOS, or Linux).
  3. Download the latest version of R.
  4. Run the installer and accept the default settings.
  5. Open R after installation to confirm it launches successfully.
Install RStudio
  1. Visit the Posit download page: https://posit.co/download/rstudio-desktop/
  2. Download the free RStudio Desktop version.
  3. Run the installer and follow the installation prompts.
  4. Open RStudio after installation.
  5. Verify that RStudio detects your R installation automatically.

RStudio is divided into several panes that help you write code, manage files, view output, and explore data. Understanding the purpose of each pane will make it easier to work efficiently in RStudio. Pane Purpose

RScript & RMarkdown

RScripts:

An R Script file is a text file containing a series of instructions written in the R programming language. These instructions tell the computer how to work with data, perform calculations, create visualizations, and generate reports. R Scripts make data analysis faster, more consistent, and easier to reproduce. Once a script is created, it can be reused whenever new data become available, ensuring the same analysis is performed the same way each time. An R Script makes your data analysis easily reproducible.

Think about creating a graph in Excel. If your dataset changes, you may need to update formulas, recreate charts, and repeat several steps manually. Similarly, in programs such as SPSS, JASP, or Minitab, you often perform analyses by clicking through menus each time. An R Script works differently. It saves every step of the analysis as code. This gives you:

  1. A clear record of how the data was analyzed
  2. The ability to reanalyze an updated dataset with the click of a single button ("re-run all analyses")
  3. The ability to fix a single error, edit one line of code, and rerun the analysis
  4. The ability to save your work midway through an analysis and continue later

This can reduce a process that might take hours of clicking to just a few seconds.

R Markdown

An R Script can perform a full set of analyses with the click of a button. However, the RScript will only run if you also have access to the raw data (e.g, the exel dataset). An R Markdown document communicates the entire research process by combining code, results, and explanations into one reproducible report. The purpose of converting an R Script into R Markdown is not simply to run code. It is to create a complete, readable report where another person can understand your analysis from beginning to end.

R Script vs. R Markdown

Feature R Script (.R) R Markdown (.Rmd)
Main Purpose Write and execute R code. Create a complete report combining code, results, and explanations.
Contains Primarily R code and comments. Code, text, tables, graphs, and statistical interpretation.
Output Results appear in the Console or Plot pane. Creates a formatted report such as an HTML document.
Sharing Requires others to have R, your files, and your script. Can be shared through a web link without requiring R or RStudio.

How to Create an R Markdown Report

The following steps describe the process for converting an R analysis into a complete R Markdown report. In this course, you will use R Markdown to organize your statistical analyses and create shareable HTML reports.

Step 1: Install the R Markdown Package

Before creating an R Markdown document, you must install and load the rmarkdown package. 

install.packages("rmarkdown")

library(rmarkdown)

Step 2: Create a New R Markdown File

In RStudio, create a new R Markdown document:

File → New File → R Markdown

A window will appear asking for information about your document.

Setting What to Enter
Title Enter your assignment or project title.
Example: Assignment 1
Author Enter your name.
Output Format Select HTML.

Click OK. A new R Markdown file will open.

RStudio automatically creates a sample R Markdown document. Delete the example text and code before beginning your assignment.

Step 3: Copy Code From Your R Script

R Markdown documents contain two types of content:

Content Type Purpose
Narrative Text Written explanations that describe your methods, results, and interpretations.
Code Chunks R code that performs calculations, creates graphs, and produces statistical output.

Copy the analysis code from your existing .R script file and paste it into your new .Rmd file.

Step 4: Convert Your R Script Into R Markdown Format

An R Script and an R Markdown document use different formatting rules.

When transferring code from an R Script into R Markdown, you must separate your explanations from your R code.

Outside Code Chunks: Written explanations, instructions, and interpretations.

Inside Code Chunks: R code that will be executed by the program.

Converting Comments Into Written Text

In an R Script, comments are created using the # symbol. Comments are notes for yourself and are ignored by R when the code runs.

In R Markdown, explanations should be written as regular text instead of comments.

R Script R Markdown 
# Calculate descriptive statistics
 Calculate descriptive statistics.

Creating Code Chunks

R code must be placed inside a code chunk so that R Markdown knows which instructions should be executed.

Code chunks begin with three backticks followed by {r} and end with three backticks. 

```{r}

2 * 2
  
```
